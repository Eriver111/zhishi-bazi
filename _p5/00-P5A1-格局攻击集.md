## 附：引擎口径提示（供审阅，非结论）

- 旺衰阈值：极强≥80 / 偏强≥60 / 中和≥40 / 偏弱≥30 / 极弱<30。
- 从格覆盖优先级：从强 > 从杀 > 从财 > 从儿 > 假从势；canCong 门控 = 极弱 + 无日支藏干根(含印) + 无天干印比 + 无支本气印比。
- 透干取格：exact 匹配按藏干序(本气→中气→余气)×天干序(年→月→时)取首个；非杂气月仅本气或同五行透干可中；全不中→同五行兜底(取本气十神+透干文案)；再不行→月令取格(必破)。
- 同柱复合格仅月干+月支搭配触发：印×杀=杀印相生 / 印×官=官印相生 / 食伤×杀=食伤制杀 / 官杀×财=财生官 / 印×伤官=伤官配印 / 财×食伤=食伤生财 / 杀×印=印星化杀。
- 成破判定：isEstablished = breakReasons.length===0；establishConditions 仅展示、不参与成破（本集已产 conditions✗仍成格 证据盘）。
- 七杀格 breakReasons 仅：七杀无制化（食神/印天干可见性，不查根不认伤官）、印星为燥土虚浮不化杀（金日主未戌月+印透）、月令受冲、极弱承载。
- 复合格 breakReasons 仅：月令受冲、极弱承载；杀印/官印相生格多一个燥土印虚浮。财破印/伤官克官对复合格只进 conditions。
- 用神：从格 xiOverride；金日主未/戌月极弱/偏弱走穷通宝鉴短路；否则 calcCandidateScores L1-L4。
