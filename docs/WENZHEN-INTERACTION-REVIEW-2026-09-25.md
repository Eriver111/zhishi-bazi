# 问真 H5 交互研究与知时改进方向

研究时间：2026-09-25。用户要求暂停古籍翻译，先研究网页流畅感。本次只写研究与交接，不修改业务功能、不推送。

- 用户提供入口：https://pcbz.iwzwh.com/#/windowphone?urlTag=h5_home
- 页面实际嵌入：https://pcbz.iwzwh.com/h5/?tag=pc#/main/wznavigation/wzindex
- 浏览器检查日期选择弹层、取消、底部记录与排盘切换。填写虚构“交互测试”，切到记录后返回，输入与原日期保留。未创建命盘、登录、付费或读取账号资料。
- 读取公开 HTML、其直接引用的同站 JS/CSS，用作架构核实。下载快照留在任务目录 work/wenzhen-fluidity，不引入仓库和生产。
- 没有测量真实手机 FPS、INP、LCP、冷启动或受控网络下双方性能。浏览器工具调用耗时不能当成站点响应耗时。以下因果判断是源码与交互所支持的工程分析，不宣称问真所有场景更快。

## 可核实的实现

1. H5 使用 Vue 2.7.14；应用代码路由 mode 为 hash，render 中有 router-view 和按 route.meta.keepAlive 条件使用的 keep-alive。
2. wzindex、wzuserlist、wzbook、paipan 等路由明确配置 keepAlive:true。记录页、学堂等通过 webpack 异步 chunk 加载；不是每次点击都请求一个新的 HTML 页面。
3. 日期控件为局部弹层：遮罩后原输入页面仍在，具备公历/农历/四柱分段、滚轮、取消与确认。公开样式存在 Vant picker、popup、tabbar，滚轮有 cubic-bezier(.23,1,.68,1) 缓动。框架或组件名称本身不保证快，也不代表所有操作都只用 transform。
4. 底部排盘/记录/学堂/我的具有稳定位置，页面内容区变化。实际排盘→记录→排盘保留测试输入，与页面缓存实现相符；不能据此断言每个页面都缓存或从不请求接口。
5. 原始 HTML 引用的 H5 app JS 约2.16 MB、两个 vendor 合计约0.45 MB、CSS约0.55 MB（十进制解码后字节），另有异步包。不是“代码特别小所以快”。没有把这些数当作浏览器压缩传输量、总下载量或首屏时间。

## 与知时当前代码的差别

- js/app-experience.js 明确保留原生整页导航，增加点击反馈、意图预取、键盘适配；手机外壳在每个页面创建。js/main.js 跳转 result?参数，而非同一个壳内切内容。浏览器返回缓存有可能复用旧页，因此不能说每次返回都重建；普通跳转仍与单页路由不同。
- js/paipan-draft.js 已有草稿、具体小时与时辰分离、账号切换清理；现有优化不是零。后续缓存不应破坏账号隔离或用旧命盘覆盖新输入。
- result.html 静态引用30个本地外链JS，文件原始大小约2.75 MB；包括 html2canvas 198,689 B 与 jsPDF 420,165 B，以及海报、深度报告、校准、聊天等功能。可优先延迟非首屏依赖。该统计不含内联脚本、图片、传输压缩、缓存命中和动态请求。
- paipan.html 静态引用本地JS约1.40 MB，主要为八字算法、县级经度及算法链。重复引用脚本可能命中HTTP缓存，但新文档仍有初始化成本；具体瓶颈需性能记录验证，不能只看文件大小。
- mo-xing-he.js 与 bg-animation.js 当前已有提前 return，持续画布循环没有启动。不能把旧版星空动画当作本轮确认的卡顿原因。书封和静态插画也不能未测量就删。
- 藏书阁内部已用 history.pushState 和同页章节渲染，是局部采用应用交互的现成例子，但不能直接把任意旧页面 HTML 插进同一容器，遗留全局变量、监听器与支付生命周期需要适配。

## 建议实施顺序（尚未实施）

1. 先记录首页→排盘→结果→返回、日期滚轮、报告展开三条链路的导航耗时、长任务和状态恢复；分冷加载/热加载、登录/游客、移动设备/桌面，不从一次网络体验估算。
2. 快速改善：PDF和海报工具点击时再加载；结果首屏只优先计算与渲染四柱等核心信息；其余内容按需准备。拆分前先确认依赖和失败重试，防止按钮点了无响应。
3. 最大的结构性方向：固定导航与页面框架，先试点首页、排盘、档案的同壳切换和有限页面缓存，保存滚动/草稿。算法调用仍沿用原接口与结果，支付和登录边界单独处理，保持可独立打开的URL与浏览器前进后退。
4. 再逐步接入结果页、合盘、紫微、六爻。账户变化清空个人缓存；命盘/算法版本变化使旧结果失效；离开页面取消失效异步任务。
5. 验收优先覆盖曾发生的问题：同时辰的不同钟点、关闭滚轮后延迟回写、“今天”把小时误作时辰序号，以及不同身份与不同命盘的缓存串用。滚轮的缓动可以调整，但不为追求动画破坏数据提交边界。

预期收益：减少整页重建与重复初始化，保留用户所在的位置和操作状态。保留现有知时视觉风格，重构重点为导航、加载和状态生命周期；具体速度提升待同条件测量。
