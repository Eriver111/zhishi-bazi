# 应事校对从泛化主题改为具体事件（2026-09-23）

## 问题定位

用户指出“枭夺食·个人事务或共同任务”等表达无法让人判断到底发生了什么。根源是历史年份身份固定为unknown，ReportImagery用daily模板将结构作用翻成通用事务；选项按钮又只显示标题，具体描述要点击确认后才能看到。

报告解锁后的应事问卷与AI对话前的命盘校对，共用chart-calibration候选与渲染；因此两者均受影响。AI自由对话另有提示词，它还会读取已回答问卷的摘要；没有检查真实聊天记录或调用线上模型。

## 修改

- 31条规则改用具体事件描述，明确对象、行为、可观察结果和不算发生的情况。共同作用方式仍留作解释依据，不作为用户直接作答的事件。
- 枭夺食：已经准备的作业/作品/申请材料，被新增检查或修改要求退回，造成延期或未能提交；正常修改且按时完成不算。
- 印重抑输出：自行反复准备初稿，尚未提交就已逾期，与被外部退回的事件区分。比劫抗杀分为加时或分担后按期交齐、加时或分担后仍逾期/未交齐；只疲累不足以确认结果。
- 在读、备考、工作、求职、居家、退休、身份未知分别使用具体对象。未知历史身份不借用现在的职业；历史学业候选保留“如果当年在读、学习或备考”前提。没有扩写成疾病、子女或亲属灾祸。
- 非家庭的通用候选也不再调用报告里的宽泛场景段落，改为可判断发生/未发生的事件题。原有领域与独立年度触发过滤保留；通用事件不能被当作某个命名机制的证据。
- 选项在回答前同时显示标题和完整题意；题干从“最接近哪一种情况”改为“哪一件事确实发生过”。保留都不符合、记不清及大致符合。
- 候选manifestation加`:e2`，语义变窄不复用旧反馈确认具体新事件。旧已答内容原样保存，新版只替换未答题；旧版已答问卷显示保留说明。如果五题都已答，不会静默重写或强制生成五道新题。
- 旧专业/场景泛化选项不进入新具体事件的正反馈权重和跨场景共同作用参考；新版专业/场景题的大致符合也不按完整结果加权。负反馈仍只作用于原选项，与新e2事件隔离。没有清除用户历史回答。
- AI账号端和游客端摘要携带题目完整描述，将机制标为“待核对机制”；旧泛化反馈带范围提示。提示词要求自由校对问题包含年份、对象、行为、结果及不计入情况，不知道历史身份时先问身份。

这些具体映射是有结构条件与年度触发限制的待核对候选，不是从十神名称必然推导出的现实事件，也没有穷尽传统取象。精确措辞不等于已验证现实命中率。没有改家庭关系、四柱、旺衰、格局、喜用忌或财富A等级；没有数据库迁移、支付或生产配置改动。
