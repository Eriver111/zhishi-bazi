# 根气克泄与官杀印通关校准

## 范围与依据

用户以“庚寅 乙酉 甲子 丙寅 女”讨论中和偏强/偏弱，授权按根气有效性和印星通关路径校准，并跨盘验证。基线为 `7aa63f2`。不是将目标盘硬编码为偏弱。

传统概念参考《子平真诠·论十干得时不旺失时不弱》：月令与通根须合看，有根可承载不等于得令或必然身强。版本可参看 <https://luckclub.cn/bazi/002/008/>。古籍没有13、6、3等计算权重，也没有证明本盘应得46分；以下为项目既有模型的条件校准。未从《渊海子平》引入规则。

## 规则

1. 统一根气结算增加同柱克/泄条件，记录透干、是否有根、是否与月支本气同五行。根气基本系数不因此再扣分；天干生克已有分值，避免一事两扣。
2. 对于得令且有根的克泄干之下的本气根，保留基本通根，但不作为“无争议双强根补偿”的候选。条件仅限制额外补偿，不认定根被拔掉，也不认定合绊天干能全力克根。失令丙火生泄寅木会记录，却不因此取消寅根。
3. 官杀月令且日主确有原规则认可的长生/禄位同五行根，才检查通关。沿用13/6/3/0工程档位：贴身透印有根或月令生源、未受本项限制，13；年干印有根或得生，6；完整本气日支藏印，6；杂藏/受扰日支印，3。原有纯透印生源规则保留，不宣称本轮已重建全部透干强度模型。
4. 印干相邻合绊限制该条路径；合化为异类则该路径为0。遥合不当作贴身强合绊。一处被合不能把另一处独立透印一起降档。
5. 透印的所有实际印根均受六冲时，限为3；有另一未受冲印根，不将日支受冲扩散到全部路径。刑害/合会沿用原根气系数，不在透印层机械等同六冲重复降档。
6. 多条印路径取最高有效档一次，不累加。审计记录各路径、根ID、限制原因、选中路径和实际分差。
7. 中和说明改为生扶/克泄耗接近，并按50分两侧说明模型倾向；不再声称五行数量均衡或一概“不偏不倚”。不新增强弱等级，不在旺衰层提前指定喜用。
