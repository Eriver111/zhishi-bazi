# 报告取象规则目录（2026-09-23）

按六类建立 31 条取象规则，基础目录有 38 个领域/表现候选；后续已增加七种生活状态的场景选择，基础表格的职场文字不再代表所有用户看到的文字，见文末“生活状态适配”。规则由既有结构事实和当年实际触发激活；现代工作、收入、学习等表现是本产品的可复核假设，不是古籍原文或已验证预测。家庭关系、四柱、格局、旺衰、喜用忌与 A 等级不变。

## 工作方式

先检查已有生克边、连续通路、成格状态、喜忌与根气，再核对当年是否确实作用到相关节点。只见十神名称、只有原局机制、无关柱位的冲、大运背景单独存在，都不足以激活新的年度取象。低强度藏根不被自动当作有力承载，从格不套普通身弱硬扛逻辑。原有已确认年度风险仍沿用前轮触发结果。

同一规则的过程与结果分开核对。比劫抗杀包含“投入很累但完成目标”和“投入很累仍未完成”两种表现；未回答时只写有依据的承压方式，不把两个相反结果同时预测。否认一种不会自动证明另一种，部分符合不计入完整专业取象的正向验证。

未作答也能在报告中看到符合条件的具体作用方式；本年、领域应期和五年摘要使用同一账本。已答反馈只匹配相同机制和表现，不训练全局算法，不改父母关系。问卷最多五题、每题最多三项，按领域轮流选入并跨题去重。

## 生活状态适配（后续修订）

用户指出职场取象过多，本轮将31条机制与现实场景分开。当前状态包括在读、备考进修、工作、求职调整、居家事务/照料、退休、未填写。新增居家入口；状态与年龄只选择解释，不增加结构触发或修改分数。

| 场景 | 主要落点 |
| --- | --- |
| 在读 | 课程、作业、答题、老师要求、同伴协作、学习物资与可支配费用 |
| 备考进修 | 复习、模拟练习、报名条件、考核要求、准备时间与预算 |
| 工作 | 保留原有岗位、项目、交付、职责及财务表现 |
| 求职调整 | 申请材料、面试表达、甄选条件、方向探索与生活预算，不假定已经录用 |
| 居家事务/照料 | 日常办事、照料分工、共同约定、生活预算及个人计划，不推断父母关系 |
| 退休 | 日常活动、兴趣作品、共同安排与生活开支，不默认继续有岗位或顾问收入 |
| 未填写 | 中性的个人任务、要求、资源与生活安排，不按成年或高龄推定职业/退休 |

- 学生与备考场景可将符合机制的任务表现落入学业领域，但仍要求该年学业领域有独立触发。未成年人不生成技能变现收入候选；费用损失与正常学习消费分开。同一机制的学业/任务落点相同时优先学业，问卷还对同一年跨领域相同文字去重。
- 年龄6—17且状态未知采用学习场景；显式状态优先。成年在读按在读展开，年轻已工作不继续套学生。未来年份沿用当前选择并提示身份改变可修改，不预测毕业或退休时间。
- 历史年份不继承当前职业。未知历史身份以中性场景提问；有学业领域依据时保留明确的“如果当年在读、学习或备考”候选，不把成年人都当作已离校。
- 场景进入表现标识，保存仍用已有字段。学校经历不能直接确认职场结局；老答案原样保留，无场景的旧答案不静默升级成某种新身份的验证依据。未知历史身份暂时只能支持相同中性场景；本轮未增加逐年身份追问或跨场景迁移学习。
