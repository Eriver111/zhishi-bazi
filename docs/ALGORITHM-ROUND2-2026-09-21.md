# 算法第二轮修复与自查（2026-09-21）

本轮在问真排盘对齐之后进行。本地修改，未提交、未推送、未部署。对照上一轮完成后的引擎，修复可复现的边界错误和内部证据矛盾；本报告不把测试通过率当成命理准确率。

## 修复内容

1. **逆排起运的交节当刻。** 出生恰好在交节时刻，逆排应取当前节，原来的严格小于比较会跳到上一个节。改为包含相等，并新增 1908-07-07 21:48 女命小暑当刻的零间隔测试。这是历法参考库边界校验，不是新增问真网页实测样本。
2. **透干通根漏掉同五行异干。** 原实现只连接与透干完全相同的藏干，例如丙见午中丁火会漏根。现在按同五行连接，根力继续使用冲合处理后的有效力量；不额外重复累加旺衰分。十天干均有对应回归。
3. **杀印补偿误用异五行根。** 原实现只要日主长生或禄的支位存在任意有效藏干就给补偿，导致己见酉中金、癸见卯中木也被当成日主根。现在要求根的五行与日主相同。实际存在同五行禄根的正向对照仍保留补偿。
4. **弱金燥土取用与润局证据冲突。** 原来的未戌月短路分支把“缺完整金根”也当成继续补水的理由。现在已判为“润局已到位”时回到正式候选比较。尚无有效润局的燥土弱金仍保留取水规则。说明文字按庚、辛实际日干生成，不再一律引用“六月辛金”或宣称水必然伤官制杀、一水三用。

未调整整体旺衰权重、档位阈值，也没有在业务代码中针对特定命盘硬编码。
