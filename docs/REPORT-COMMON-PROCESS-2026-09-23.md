# 共同作用方式与跨场景参考

用户进一步澄清：同一种取象应保留共同逻辑，例如自主表达与权威要求的冲突，在学校对应师长/校规，在工作对应领导/制度。上一轮将具体结果隔离是必要的，但把共同作用方式也完全隔离过于严格。

## 当前实现

31条取象规则均增加 `commonProcess`，统一采用“结构条件 → 共同作用方式 → 当前人物与事项 → 具体结果”的解释顺序。定义集中在 `js/report-imagery.js`，不是只增加伤官见官一个例子，也没有修改生克计算。

| 规则示例 | 共同作用方式 | 场景中的人物和事项 |
| --- | --- | --- |
| 伤官见官 | 自主表达与权威要求的张力，可能表现为质疑、反驳或不愿直接服从 | 师长/校规、领导/制度、审核人员/办事要求 |
| 印扶身 | 借助资料、指导与方法获得支撑 | 答疑/教材、培训/经验、日常信息与办事方法 |
| 比劫抗杀 | 靠自身持续投入或同伴分担承压 | 课业、考核、工作任务或生活安排；过程与完成结果分开 |
| 伤官配印 | 把分散的想法整理为系统、规范、可检验的成果 | 答题/作品、专业输出、个人表达 |
| 食神制杀 | 用熟练技能和可执行办法应对难点 | 考试训练、实际任务、生活难题 |
| 财制印 | 现实需求推动行动，减少过度准备 | 学习期限、实际预算、交付或生活目标 |

“不服从、挑战权威”是取象框架里的可能表现，不把一次外部冲突直接当作固定人格，也不声称结构或往事已经证明心理原因。规则仍须满足原有条件与年度独立触发。

## 两层反馈

- 同领域、同机制、同表现与场景：仍按既有 `adjustments` 处理，可修正相应的报告候选。
- 同一命名机制、不同场景或领域：新增 `processReferences`，仅作为共同作用方式的参考。它不确认新场景中的具体事件、不提高原始评分、不改变事件排序，也不参与成功/失败分支的选定。
- 例：已完整反馈学校时期的表达冲突，可给职场的同机制解释增加共同线索及原始年份依据；不能因此确认会顶撞某位领导、受处分或丢工作。比劫抗杀的“累但完成”也不能跨场景证明下一次会完成。
- 必须是完整符合的历史反馈；部分符合、记不清、未来答案或没有本年独立触发的候选，不提供这种参考。按实际年份去重；同类解释有反例则一起保留，不将线索写成稳定人格或必然规律。
- 只否认具体结果不代表否认底层作用方式，因此不会由一条“都不符合”反推性格/心理；同时也不会凭负反馈生成正向共同线索。
- 来源与目标的机制、表现标识须能在规则库中验证。没有身份标记的旧命名选项可提供共同作用方式参考，但保留 `unspecified`，不会补造学生/就业身份。旧宽泛选项、伪造机制/表现、家庭选项均不能进入这层参考。

报告本年、领域应期、五年摘要消费同一条共同线索，复核区域按机制与来源合并多个未来窗口，折叠展示原始反馈；网页/PDF继续转义文字并保留依据。撤销反馈后共同参考随之移除。基础四柱、旺衰、格局、喜用忌、A等级、父母模块及AI聚合规则不变。
