# 知时藏书阁第一版

用户澄清由开发侧找书，不等待用户上传。藏书阁保持为知时站内的一个阅读功能，不另起产品或新增付费体系。

## 内容

首批《滴天髓辑要》《紫微斗数全书》卷一至三、《增删卜易》四卷来源录本，共 275 个阅读分节。实际字形保留来源，界面使用简体书名。采用公有领域古籍与维基文库录文，逐书列出处、修订信息、署名与 CC BY-SA 4.0；详见 `books/LICENSE.md`。不包含未经授权的现代译注，也不虚构 AI 生成的“古籍正文”。并非逐字校勘本，不能把录文本身或古籍观点作为算法准确率证据。

用户指出阅读页繁体不便后，改为**默认简体正文、标题与目录**，底部“原文/简体”按钮可切回原文字形并记住本机偏好。`scripts/build-library-simplified.cjs` 使用锁定的开发依赖 opencc-js 1.4.2 预生成对应字段，导入脚本同步调用；不在浏览器运行转换器或依赖外部 CDN。原 text/title、章节 ID、段落顺序保持不变，进度与收藏共用，不重新生成章节。该功能是字形转换，不做白话翻译；罕见异体字与自动转换歧义可对照原文。

`scripts/import-library.cjs <snapshot-directory>` 从预先下载的 MediaWiki action=parse JSON 整理章节；所需文件为 ditian.json、ziwei1.json、ziwei2.json、ziwei3.json、zengshan.json。快照字段为 text、revid、sections，页面标题分别为《滴天髓》《紫微斗數全書/卷一》《紫微斗數全書/卷二》《紫微斗數全書/卷三》《增刪卜易》。导入在离线浏览器 DOM 内完成，不把来源 HTML 交给读者执行。更新书稿必须检查章节稳定标识、前后文、增删范围及既有进度兼容。

## 界面与阅读

- `/library` 分类/搜索书架，桌面首页“更多”及手机侧栏“阅读”入口；不增加底部导航数量。
- 同一页打开书籍，按需载入对应正文，支持目录、章节收藏、上下章、字号、日夜读、继续阅读、浏览器返回及刷新恢复到段落。
- 封面使用与现有风格一致的纸本装帧和文字，不添加 emoji 或无意义占位图片。
- 阅读时手机底栏切换为阅读工具。目录/出处使用原生 dialog，正文纯 textContent 渲染，卦例单独横向滚动，不扩大整页宽度。
- 游客可直接阅读；保存范围明确为同浏览器。游客与每个账号使用不同本机 key，不自动把此前访客的阅读记录归到新登录账号。

## 账号同步

新 `/api/library-state` 使用现有 `user_data` 表，每书 `library_v1:<bookId>` 一个 key，不需要数据库迁移。仅从鉴权结果取 user_id，校验书籍范围、数据体积、章节、段落索引及时间。返回内容禁止缓存。

合并最新进度与逐章收藏时间戳，取消收藏保留墓碑，避免另一设备旧记录复活。数据库更新按读到的原 value 做条件更新；首次插入冲突或并发更新时重新读取、合并、重试，失败明确报错，不使用会吞掉错误的通用 syncUserData。

前端本机先保存，再同步。服务端失败显示重试；旧账号的迟到响应不影响新账号视图。首次打开书籍等待账号恢复，4.5 秒同步超时后仍可用本机记录阅读，同书换章不反复等待云端。首次换设备需打开相应书籍才能拉取进度，书架“接着上次读”本身使用本机已有记录。进度时间戳允许 5 分钟时钟偏差，不提供任意严重时钟错误下的自动纠正。
