# 往事问卷跨题去重（2026-09-23，未推送）

用户同意按事件含义去重，并保留少量有依据的跨年对照。本轮基线为交接第32节完成后的源码；与git基线的差异包括此前九批工作，不可全称为本轮修改。

## 选题变化

- 七类及28项通用细分保持。先保留有独立年度触发的候选，再按领域、表现类型及家庭对象分组去重；同一表现换措辞或换十神机制不会自动成为新题。另对详细文本去空白/标点后的完全重复设限。
- 同一年泛化的“生活变化”与具体学校、工作、家庭、感情候选共享触发位置及类型时，保留具体事件；触发不同的环境变化和个人财务不一概排除。父亲与母亲分别保留。
- 原先先截前三领域再过滤，会漏掉有独立依据的其他候选；现先过滤、去重后再限制每题最多三项。仍优先人生阶段覆盖、每份最多五题，同主类别最多两题；不足时不凑数。
- 优先无重复的新信息；有空余名额时，每份新问卷最多留一组同领域同表现同机制的跨年对照，双方均需独立触发且年份相隔至少三年，避免±1年回忆范围重叠。题面明确解释对照目的、允许两年都不符合。没有宣称两年必然发生同类事件。
- 选项证据若旧取证函数未找到内容，读取同领域的年度裁决证据，避免已有年度依据却呈现空依据；不补造结构结论。

## 已有反馈

候选版本升为bazi-cal-v6，chart-calibration资源16。账号端沿用既有升级API，在生成新候选时传入已答题作为去重基线；后台仍只替换未答题。游客增加候选版本标记，同样保留所有已答原题/选项/答案，只替换未答；保存失败回退到已有本地内容。无可用引擎时不清空旧题。

旧题没有独立触发元数据时，不用它作为新增跨年对照的证据。已答旧题即使重复也原样保留，因此下面的新问卷统计不能套用于所有既有用户问卷。没有数据库迁移或生产数据修改。
