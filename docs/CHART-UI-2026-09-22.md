## 实现

- 新增 `disclaimer.html`：说明传统文化与 AI 内容的局限、使用边界、各类购买权益、订单异常反馈和售后权利。19 个公开页面加入入口；个人报告、合盘和积分会员购买位置加入须知。静态资源白名单仅增加免责声明页面。
- `js/service-notice.js` / `css/service-notice.css`：动态购买提示保持幂等，聊天页入口放入底部栏；为报告购买遮罩预留空间并修复深色背景下的可读性。合盘购买按钮原来的“积分解锁”改为与现有现金购买流程一致的说明，支付请求逻辑不变。
- `js/chart-experience.js` / `css/chart-experience.css`：合盘与紫微使用出生信息摘要及原生 dialog 弹层，保留原始控件、ID、选择项、监听器和排盘设置。不支持 dialog 的浏览器保留原表单。键盘 Esc 可关闭，焦点返回入口；修改即时生效，完成按钮关闭弹层。
- 合盘：甲乙身份卡、手机分步编辑、桌面并排、档案填入后刷新摘要。浏览器验证发现原来的数据交换只保留时辰值，丢失同一时辰内的精确小时。现额外保存 `data-clock`、重建日期选项、清理空身份的残留性别和地点；档案填入也保留 clock。增加三项实际数据传递回归。未调整命理计算规则。
- 紫微：移除无实际加载依据的强制开场等待；命盘总览/专业解读双视图支持方向键切换。手机完整十二宫可在图内横向滑动，点选或键盘激活宫位，在下方读取当前既有盘面的星曜、庙旺与四化数据。
- 六爻：三步提示、六爻进度、起卦后问题固定、防止动画中重复点击、本卦/变卦对照和明确重新起卦操作。消除旧动画初始透明度导致爻线不显示的问题。起卦随机过程、纳甲、历法、计算逻辑未改变。
