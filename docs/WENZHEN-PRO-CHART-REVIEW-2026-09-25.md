## 本次实际操作

- 从用户给定入口 https://pcbz.iwzwh.com/#/windowphone?urlTag=h5_home 进入手机 H5，在未登录、保存开关关闭时，用页面默认2026-09-25 17:19生成“案例1”测试盘。不使用真实出生资料、不登录、不付费。
- 查看“基本排盘”“专业细盘”，专业页选择2041年起己亥大运，再选择2047丁卯流年、清明甲辰流月；展开“将星”解释，关闭，再切换基本排盘与专业细盘。对大运行执行横向滚动。
- 观察为内嵌手机界面（约414像素宽）在桌面浏览器的行为，不等同于真实手机触摸延迟、帧率或性能基准。横向滚轮滚动成功；鼠标拖动未观察到明显位移，不能据此宣称已验证触摸拖动。

## 盘面结构

1. 标题与四个栏目固定在顶部：基本信息、基本排盘、专业细盘、断事笔记。向下滚动时栏目仍可用。切换栏目可观察到横向过渡。
2. 基础盘以本命四柱为中心；专业盘将流年、当前大运（起运前是小运）放在本命四柱左侧。选择流月后又在左侧加入流月列。各行沿同一列网格对齐。
3. 依次显示主星、天干、地支、藏干与对应十神、星运、自坐、空亡、纳音。干支大且使用稳定五行色，辅助字小、颜色较淡。专业盘的藏干和十神合在同一条目，避免再铺开一组高行。
4. 主表后接简短的起运、交运、年龄等信息，然后连续排列大运、流年、流月。没有在每一部分前插入大块介绍或报告。
5. 下方才是季节五行状态、天干/地支关系提示、四柱神煞、大运神煞、流年神煞。神煞长列表不占满主表，使最常比较的干支与岁运靠近。
6. 表格以浅底、少量细分隔线为主，非每个干支一个独立圆角卡。选中项有背景及字重反馈。截图中的年龄、日期和列数均随本次测试盘变化，不应写死。

## 知时已存在的能力与差距

- result.html 已有流年/大运/本命四柱的对齐表，以及星运、自坐、空亡、纳音和神煞数据；并不是缺整套八字表格。
- css/mobile-app-shell.css 后段将 `.pp-aux-row` 与 `.pp-shensha-row` 在手机端隐藏。专业细盘应恢复星运等短行；神煞可改到下方独立紧凑区。基础盘可保留简化视图，不把所有信息强塞给新用户。
- 同文件主表普通格最小高42px、藏干与副星各最小高66px，岁运条亦有较高最小高度。可以针对专业模式压缩非交互行、合并藏干与十神，保留实际可点击控件的触控面积，不能把所有按钮一律缩小。
- js/result.js 的 showLiuNian 会清空原流年列；renderLiuNian 仅在这步大运含今年时自动选择当前年。因此切换到其他运时，上方流年可暂为空。对齐问真感觉应明确规则：进入当前运选今年，进入其他运自动选首年或该运上次查看年份，并同步所有依赖视图，不留下新大运与旧流月混搭。
- 现有手机三个栏目是基础排盘、专业解读、白话详参。“专业解读”是判断说明，不等于“专业细盘”。后续需单独提供专业细盘模式，把工具盘与报告阅读分开；保留已做的旺衰、格局、喜用忌和父母关系功能。
- 现有大运/流年点击已局部更新表格，也有结果视图状态保存。应沿用并补全依赖关系，避免为了视觉重新造算法。

## 实现验收建议

1. 以专业盘首屏为对照：主表、起运信息、大运与流年紧密相邻；字段列顺序、字号层次、五行色、留白和分隔线分别核对，不用“整体像了”代替验收。
2. 当前大运/年份/月份成为同一组有依赖的选择状态；年份变化使旧月份的日期与作用重算；出生参数或算法版本变化时废弃旧盘选择，账号切换不能串用。
3. 点按先更新选中反馈，已有数据局部替换，异步补充只覆盖对应目标；连续切换防止旧响应回写。不会每次点年份整页跳转、滚到顶部或重生成AI报告。
4. 岁运横向滚动与页面纵向滚动独立，短按选择、滑动浏览分清；切栏后的状态保留规则明确。术语解释就地展示，关闭恢复原位置与焦点。
5. 流月等尚未完成同等可靠性验证的能力，先核对本地算法与数据来源，再接UI；不可只做看似能动的月份按钮。会员入口和未观察的功能不臆造。
6. 提供320/390/414手机宽度和桌面检查，重点覆盖起运前小运、跨年大运、不同生日与性别、日期边界、未知时辰、数据缺失、连续点选、身份切换。此前同一时辰的两个钟点、关闭滚轮后延迟回写、今天按钮的小时/时辰索引混淆仍为必测回归。

界面密度、盘面排列与操作节奏以实测问真专业细盘为参照；站名与品牌资源用知时，计算依据继续使用知时自己的可验证规则。未复制问真的专有解释文案、图标资源或源代码。


## 本轮实现与用户最新取舍

用户明确重点是 UI 设计和操作感觉，保留星运、自坐、空亡、纳音，不再展示目前不可靠的神煞。本节覆盖前文“神煞移至下方”的实现建议；对问真的观察记录仍保留。

- 手机结果页四栏目：基本信息、专业排盘（默认）、专业解读、白话详参。基本信息收纳出生资料和分享/海报入口，下载横幅归白话详参；沿用原视图状态键及独立栏目滚动恢复。
- result-pro-chart.css 为独立结果页覆盖层：平整浅底盘面、无卡片阴影、紧凑辅助行、藏干与对应十神同项排列；大运/流年接在主盘后，起运时间与所选十年范围可见。横向岁运条与纵向页面均可滚动。
- 四个辅助行在手机恢复，原单独副星行在手机隐藏（十神合入藏干），神煞行全宽度隐藏，未删除底层算法或修改报告判断。桌面保留原报告布局。
- 切运直接选今年（如包含）或首年；未改变大运起算和流年干支计算。岁运采用原生按钮、aria-pressed、键盘聚焦反馈；选中样式不与实际当前年份混淆。
- 导出副本把岁运按钮转换为静态格，避免既有“去掉按钮”逻辑误删岁运；移除合并藏干内的重复十神，保留导出原副星行。
- 未添加流月、流日、小运计算或同壳路由，也未实施上一份性能文档中的依赖懒加载。不得宣称已完全复制问真所有功能或经过真机帧率验证。
