# 家庭模块整体校准

用户要求校准整个家庭模块，目标是判断准确、具体且有购买参考价值，而非仅制造文案差异，也不是将每一段都写成“不能确定”。用户举无印的例子用于说明意图，不是授权将“无印必然母子不和”写成规则。本轮承接报告升级后的本地源码，仍在 main / bc34314，未提交或推送。

## 五段统一判断

`analyzeParents` 方法版本改为 `parents-v6-family`，五段为原生家庭与成长方式、父亲对你的影响、母亲对你的影响、父母之间的相处、你与父母的互动。

正文先给各段的具体结论，说明与限制留在“依据与条件”折叠详情中。保留必要的单段未知状态，不用未知段覆盖已有方向的其他段。页面的简短总说明明确传统推断属性。父母星固定采用项目既有偏财/正印口径，不随性别交换。

### 规则变化与必要条件

| 维度 | 本轮条件 | 撤销的跳跃 |
| --- | --- | --- |
| 家庭支持 | 年月出现的专属父母星，结合有效根气、核心喜忌与对应支持/压力判断 | 移除旧 foundationScore；财印共现不再扣分，食伤偏财共现不再加家境分 |
| 成长方式 | 年月透干和本气，同主题必须出现在两个不同柱位 | 同柱两个十神、任意余气不拼成整个家庭画像；不推出父母职业 |
| 父亲/母亲支持 | 专属星出现、有有效同五行根气、属有利方向，并有早年或本人结构连接 | 仅透干、仅数量、仅位置不能确认支持；不把支持等同情感亲密 |
| 责任压力 | 专属星出现、有根、属不利方向且有本人结构连接 | 仅年柱背景位或单一忌神不输出本人关系压力；不把压力等同不爱 |
| 互动摩擦 | 专属星出现且连接本人，父母星有效根实际受到同一组年月—日支关系的扰动 | 不把时年之间的根气受扰借给无关月日冲突；不把一般宫位受扰判为每位父母关系差 |
| 父母之间 | 父母专属星分别有年月落点，落点各有同五行根，双方不同柱位存在实际地支作用 | 不用年干支生克指定谁强势，不用任意年柱受冲推出父母婚姻失和 |
| 亲子综合 | 汇总各自支持、责任压力与摩擦，保留混合方向 | 不将有条件支持总结成一路顺畅；不把相合本身判作冲突 |

根气继续消费主引擎结算快照，不新增根气分数或旺衰权重；根的冲刑害扰动与合会牵引分开。支持条件成立但根气被扰/牵引时，描述帮助落实有条件；只有相应作用链支持摩擦时才描述互动拉扯。合会牵引不等于成化。

专属星不显时另存正财/偏印辅助线索，保留父母身份口径，不把“正印不显”写成“全局无印”，也不把辅助同类星冒充母亲本人。缺少专属线索不推断缺席、失爱、离异、疾病或寿命。

### 数据与消费

每段 `claims` 增加 direction、requiredConditions；同步 `judgements` 保存支持/压力/摩擦各自条件，保留反证与 `realityConfirmed:false`。`symbolic`、`insufficient` 是规则状态，不是现实命中率。family/child 中的条件列表是多分支诊断，不能当成全部必须为真的单一路径。

兼容旧的五段文本、parentStars、palace、nearScore/farScore、family.level 等字段。近远分仍仅是位置度量；family.level 改为由各维度方向派生的兼容字段，不再由旧积分产生。旧 businessPattern/wealthBlocksSeal 仍为 null，共现标记只记录线索，不参与新的家庭支持计分。

AI 上下文收到每段方向、证据、条件和反证；明确 mixed 必须保留两面，insufficient 仅约束该段，不能改写成父母不爱或整段都无法判断。未调用真实模型；提示词传递测试不代表自由文本永远遵循。

核心六个入口 `bazi.js?v=20260923d`，结果渲染 `result.js?v=45`。deep-report26、chain12、pro-analysis20、hepan-core5、hepan-result6 保持。

## 验证与边界

- 新增家庭专项测试，覆盖辅助星、撤销有效根后的支持回退、中性/不利分流、仅背景位、月日冲突、根气作用归属、双方真实落点、共现不加减总分、成长主题跨柱条件、混合结论及 AI 传递。
- 256 个生成日期各跑男女，共 512 次家庭分析；验证性别对称、条件闭合、来源、反证和根气；这些是合成结构回归，不是 512 个真实家庭反馈。
- 5,000 日期（4,961 组不同四柱）与本轮开始前源码比较，旺衰、从格、取用、格局及账本等 15 维均 0 变化；历史 53 盘 0 变化，原始 CSV 未修改。A6—A10 评分代码本轮未改，代表等级回归保留。
- 页面测试检查五段结论、折叠依据与转义；没有进行本轮手机视觉测试。
- 最终 109 个文件、1,210 项隔离回归通过（本轮新增 13 项），无失败/跳过/取消。41 个 JS、8 段内联脚本、14 处版本引用与差异检查通过。与本轮快照比较，`bazi.js` 家庭分析区域以外内容完全一致。

这是对传统解释规则与程序一致性的校准，尚无独立真实家庭反馈集，不能称为已证明现实准确率提升。新增的组合门槛是明确记录的项目规则，不冒称古籍中的数值标准。后续若用真实案例评估，应在查看反馈前冻结原判断，按支持、管教、亲疏、父母相处分维度统计命中/错误/未知，不事后改写旧结论当作命中。
