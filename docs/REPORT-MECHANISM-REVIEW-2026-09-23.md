# 报告内机制复核（2026-09-23）

## 范围

用户明确：校准只修改报告内内容，不修改家庭关系；核对的是具体专业解释是否对应实际经历，例如“财破印”的某项解释是否表现为钱财损失。不能从问卷反馈改写父母关系，也不能把一次符合称为机制因果成立。

本轮不新增家庭实际情况问项，不向父母段落、AI 上下文或基础排盘回写反馈。现有家庭关系分析、四柱、旺衰、格局、喜用忌与 A6–A10 计算保持原样。账号往事记录仍沿用原 API，未改数据库结构；当前状态仍按设备、账号及命盘隔离。

## 行为

- 已明确触发的财破印/财坏印/财印冲、比劫分流、伤官见官、枭夺食、官杀压力等五组命名机制可生成具体表现候选。只见财星、印星或财制印，不补造“财破印”；规则名来自已有触发/风险账本，不重算改盘。财破印的损失候选明确排除正常消费和储蓄转投资，另有学习准备受干扰的候选；二者分别匹配领域和表现。
- 匹配需要同领域、同机制、同表现，并且未来年份自身有独立触发。否认其中一项不等于否认整个领域。同一年度可有同领域的不同机制；拒绝“财破印对应损失”不会撤掉另一项有依据的“比劫分流”候选。
- 否认或正反并存的具体解释退出重点；其他独立触发候选递补。重复支持仅在结构分相同的候选间作为排序辅助，单次反馈不提高确定程度。没有替代依据时不编造相反结论。
- 年度正文、领域应期、五年摘要和报告主线读取同一份修正后的事件账本。年度原始结构、分数、风险与救应数据保留；受复核年份不另行展开未标注具体机制的旧风险/缓解/宽泛领域文案，避免通过旧文案重新断言已撤下的表现。五年汇总在存在复核时不展开缺乏机制归属的大运共同文案。
- 原解释及修改依据保留在折叠详情中，PDF 展开详情。清除或修改答案从复核前的原账本重建，避免叠加旧修改。未匹配到具体机制的其他段落保持原状。
- 旧题已答内容不改。新专业机制使用独立键，旧宽泛十神标签不会被当作这条专业规则的历史验证。否认记录也按具体表现分开，不能拿一个表现未发生推翻另一个表现。

## 边界

这是报告的解释选择与一致性处理，不是重新训练全局命理算法，也不是现实命中率或因果关系的验证。没有实现任意自由文本的自动事实抽取或全篇自然语言矛盾证明。报告外父母关系不参与回写。旧算法中未归属命名机制的场景仍保留原有机制键，不将其冒称为本轮新增的专业规则验证。

专业规则问项仍遵守最多五题、同主领域最多两题以及跨题去重；不会因为加入命名机制而堆满问卷。同 64 个合成命盘、加载当前全部依赖后共 317 题/657 选项，61 份五题、3 份四题；详细文案重复 1/657（0.2%，明确跨年对照），整组选项重复 0，标题重复 27.7%。这些是问卷重复率，不是准确率。
