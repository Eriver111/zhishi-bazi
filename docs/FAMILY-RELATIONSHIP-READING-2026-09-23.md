# 父母关系恢复具体、连贯的生活化解读

用户要求达到旧版的具体程度。此前 v7 解决了空段落过多，但正文仍短而抽象；本轮 v8 在不恢复旧版过度推断的前提下，展开能得到的帮助、相处感受、亲近与自主的拉扯、沟通分歧以及成长影响。

## 解读分支

父亲、母亲分别消费现有支持/责任压力/实际根气摩擦的判定，而非随机选择文案。共十类父母解读：

| 分支 | 展开的内容 | 主要约束 |
| --- | --- | --- |
| help_available | 具体帮助、通过实际配合建立联系 | 专属星、有效根、有利作用、本人连接，支持无牵制 |
| help_constrained | 有助力，但计划中的帮助与真正落实之间存在落差 | 保留根气受扰或牵引条件，不补写争吵 |
| help_with_friction | 能得到帮助，也想自己作主；具体沟通分歧 | 支持与实际同一家庭—日支根气受扰同时成立 |
| expectations | 怎样被要求、为何感到需要证明自己或争取决定权 | 实际个人责任压力，不凭忌神单点生成 |
| expectations_and_friction | 要求与实际分歧同时展开 | 责任压力、局部摩擦两条条件同时成立 |
| friction | 具体安排的冲突及沟通卡点 | 不把摩擦凭空写成支持或父母不爱 |
| interaction_theme | 实际事务/照料中的可观察主题 | 中性仍为中性，不升级为控制或疏远 |
| early_support | 成长阶段的资源与照顾条件 | 仅早年落点不扩展到当前亲疏 |
| early_support_constrained | 早年有助力，同时保留帮助落实的限制 | 不能把 mixed 因为是早年就写成一路顺畅 |
| early_theme | 成长中责任、照顾与安排的主题 | 不写当前关系或父母性格 |

已成立的局部摩擦再按实际同一作用事件分为三种沟通候选：正面做法冲突、标准反复、双方感受错位。这里只消费命中父母根气的事件，不借用其他柱的冲刑害。多种作用并存时择一主线展开，避免叠加互相冲突的性格描述。

这些生活化表达是项目对传统结构的候选解释，不是独立验证过的心理或家庭因果规律。身体健康、职业、寿命、离异、固定联系频率等旧版跳跃没有恢复。

## 输出与阅读

- `claims[].reading` 保留主句、分支、范围及每段的 `requiredConditions/sourceRefs/realityConfirmed:false`；每段依据可追溯，不能通过多写字绕过成立条件。
- 兼容 `fatherText/motherText/familyText/childRelationshipText`，分段标题与正文仍包含在这些字段中，其他入口和 AI 能收到完整文本。
- 家庭成长主题增加家中常见评价标准；亲子综合增加父母作用不同时的分别解读，不由双方对孩子作用不同推断他们夫妻不和。
- 网页按段落排版，标出“能得到的帮助”“相处中的感受”“沟通容易卡住的地方”等。只调整父母卡片的字号、底色与间距；原本缺少依据的段落继续集中折叠。PDF展开详情且文本一致。
- AI提示词要求保留具体生活内容，不压缩成资源/边界词语；时间范围与逐段条件一并传递。没有实际调用外部AI，提示词测试不等于自由回答硬保证。
- 往事复核继续只修改报告解释，不回写父母关系。

## 例子：同一合成盘中的两种不同作用

合成四柱：癸未、庚申、甲寅、戊辰。

父亲部分展开“要求落在哪里、相处中的感受、沟通容易卡住的地方”：

> 更看重花钱是否值得、做事是否有结果、该由谁承担责任。你提出自己的选择时，容易先面对现实得失的衡量，受到的评价也更偏向事情做得怎样。

母亲部分展开“能得到的帮助、帮助为什么会打折”：

> 能得到照顾与安排上的助力，实际执行却容易打折。计划里有人帮忙，与最后有人能腾出时间把事做完，是两个环节；这一侧的落差更集中在后一个环节。

母亲这一支没有被写成争吵。亲子综合则说明两侧作用不同，而非给出全家关系好/坏的统一标签。这是输出示例，不是合成盘对应真实家庭已被验证。
