# 报告与父母关系：论证关联审查及产品改进方案

日期：2026-09-23。用户要求检查每段论证与结论的关联，兼顾准确度与卖点。此轮是源码审查、合成样本复现与方案记录，尚未修改报告或父母关系业务代码；A6—A10分级保留。

## 结论与审查范围

当前不能将每段正文都称为强关联，更不能称为现实必然关系。需要分别检查三层：

1. **程序事实**：四柱、十神、位置、显藏、主引擎旺衰等，能用程序复算。
2. **规则推断**：在明确的传统判读体系内，某个结构是否满足条件、有没有反证。规则内一致不等于已证实现实相关性。
3. **现实结论**：父母谁强势、配偶样貌、最终学历、终身财富金额等。不能仅由前两层的字段名称推出必然结果。本轮没有取得能够验证这些现实结论的独立经历样本。

审查覆盖`js/deep-report.js`的整份报告主线、财富、婚恋、学业、当年、五年和领域应期文案生成器，以及`js/bazi.js`中实际导出的`analyzeParents`、结果页渲染与父母AI上下文。旧`analyzeParentsLegacy`不是当前入口，未将它的文案误列为现有线上结论。

源码逐段检查与256个生成日期样本相结合。样本生成种子`0x092324`，1960—2010年，每月1—28日、24小时，男性，报告锚点2026年；未读取用户档案。生成输出覆盖婚恋43种标题、财富9种、学业8种、当年9种、五年3种，含动态标题的不同变体。这个范围不是所有可能命盘、所有女性分支或所有自由AI回答的穷尽证明。

## 为什么已有测试通过仍有这些问题

已有1,183项回归主要证明既定程序契约和历史规则输出。本次发现旧父母测试还明确要求“年支克年干→母亲强势”等句子；此类测试能防止文案变化，不能验证现实父母关系。报告测试也有保证A6下限、检查固定文案的断言。这些不是实际经历的独立真值。

因此后续不能为通过旧断言继续保留错误推断，也不能把刚改的句子复制到测试便宣称更准确。应测试证据缺失、矛盾和跨模块传递，并另建现实验证集。

## 建议的实现与展示

### 第一步：修明确矛盾，不改卖点骨架

优先修本报告复现的七类问题：合与冲分流、根气事实统一、透藏枚举、年龄未定、渠道综合判定、财富主旺衰一致、从格主线。空输入停止生成个性化结论；保留A等级卡片、婚恋画像、学习主题和年度窗口。

### 第二步：给每个结论增加证据约束

每条结论记录`claimKey / sourceRefs / ruleId / requiredConditions / blockers / status / scope`。`status`区分可复算事实、规则条件支持、传统象征线索、信息不足；这些是证据状态，不是经验命中概率。

- 先查必要条件和反证，再生成文案。同一个地支及其派生十神不能重复算三份独立支持。
- 首段只放当前最有支持的结论。反证明显时不能用“也可能”把正反两种情况都包进去。
- `sourceText`要指向具体事实和规则，不用“分数高，因为层级高”循环论证。
- 底层`limited/unclear`和缺失字段必须传到正文，不让叙述层补成明确答案。
- 每段必要条件可展开查看；跨段依据去重应保留引用链接，不能直接清空后失去可追溯性。
- AI、页面、导出读取同一结论对象，不能由AI在已有等级后自行补外貌、金额、疾病、亲人态度等新事实。

### 第三步：保留可读性和期待感

建议每张核心卡片采用“明确主题 + 两项主要依据 + 一个最关键条件”的结构，证据详情折叠。不要满页工程字段，也不要每句话都堆“可能”。卖点来自个体差异、具体结构和可核对的条件。

- **财富**：A等级继续醒目，说明评级最主要的支持/限制；路径、承接、留存和窗口分开。保留吸引力不要求承诺某个金额。
- **婚恋**：保留相处画像和重点窗口；把年龄/外貌/渠道放辅助线索层，不把弱项包装成强项。
- **学业**：保留学习类型、优势与深造窗口；将学历陈述绑定现实教育进度，不用出生盘替代考试结果。
- **父母**：保留“家庭支持、父母相处、你与父母”主题；资源帮助、情感亲近、决策分工分别表达，避免以“父母好坏”作总裁决。

现实校对可选，提供“不符合/不愿提供”的出口，不强迫用户在预设故事中二选一。原始命盘推断与用户补充后的解释分开保存并标明来源，不能吸收用户答案后倒称命盘早已准确预测。

### 验收方式

1. 对七类已复现问题建立正反例；增加女性、未进入大运、从格、旧缓存等样本。
2. 反事实测试：删除关键证据应降低结论；新增阻断应撤销相关判断；调整无关神煞不应改变父母亲密结论；数组排序不应改变认识渠道。
3. 语义一致性：主盘中和不得写偏强；未定不自动变相仿；透藏并见不得当未透；没有现实资料不确认父母职业与既往经历。
4. 保留原回归并明确更新理由；不能靠改历史CSV制造一致。
5. 经用户同意另建去标识、预先固定问题和时间窗口的真实反馈集，记录命中、未命中、不适用与无法验证。校对前后的结果分别统计，保留未参与调参的样本；没有这一步，不公布现实准确率。
