# 算法第三轮：调候一致性与财官印成格条件

日期：2026-09-21。基线：已推送的 `f585cb8`。本轮为本地修改，未推送、未部署。

## 调候需求与满足状态统一

原实现以指数 ≥2.5 判定需要暖局或降温，却允许指数 <3 时宣称暖局、润局已经到位。在 2.5—3 区间存在两种结论同时成立的错误。

现在满足状态直接消费 `needsWarmth` / `needsCooling` 的终裁。原有季节入口、冷热指数、有效火水载体条件保留；“缺火”“缺水”仍只是载体描述，不自动推导需要补该五行。

回归覆盖 2.5、2.6、2.95、3 的实例，以及季节门槛以外的反例。样本「丁巳 癸丑 甲申 乙丑」寒指数 2.6，继续判需要暖局，但不再同时宣称暖局已到位。

## 财官印相生不再只凭三者透干有根升级主格

复用仓库已有官印结构层的“印为核心用神”口径，并检查三类具体证据：

- 财印是否贴邻，存在直接相克而官星不在其间的情况；
- 三个节点之间是否存在天干五合牵制；日主合身不套用这一节点互合限制；
- 原局是否已经触发厚土埋金或水多木漂，导致“印多即生身”的解释失效。

有根仍是必要条件，但不自动证明通路有效。上述证据未满足时记录为“条件待定”，保留月令基础格局；不把贴邻或五合直接断成必然破格、必然合化。缺根等原有硬破条件仍保留。该修改是现有模型内部口径与证据检查的收紧，不代表各流派统一规则。

没有增加旺衰分数阈值，没有用单盘特判，也没有把后置格局反写到旺衰评分或喜用候选中。

## 结果页、报告与 AI 上下文

后置结构新增保留 `pendingReasons` 和 `establishConditions`。待定原因不再混入 `breakReasons`。结果页和专业报告展示待核依据；AI 上下文传入这些依据，并明确待定结构不能冒充已经成格、已经破格或当前主格。测试验证的是上下文构造，未调用外部模型验证实际生成回答。
