## 2. 格局判定（`getPattern` 4123–4294）

### 主规则：《耕寸集》透干取格

1. 取月支藏干（本气→中气→余气），依次检查是否透出于年/月/日/时任意天干
2. 第一个透出的藏干对应十神即为格局
3. **杂气月（辰戌丑未）任何藏干透出皆可取格**（v5.2 修正：不再只认本气）；四生（寅申巳亥）四正（子午卯酉）月只认本气
4. 都不透 → 取本气十神；兜底：建禄格/印绶格/杂格

### 同柱复合格局（月干+月支组合，命中优先返回）

杀印相生 / 官印相生 / 食神制杀 / 伤官制杀 / 伤官配印 / 印星化杀 / 财生官 / 食神生财 / 伤官生财

### 成格/破格（`finalizePatternStatus` 4006–4121）

- 破格原因例：正官格见伤官（伤官克官）/官杀混杂；七杀格无制化；食神格见偏印（枭神夺食）；伤官格见正官；月令被冲；日主极弱难承载（从格成立除外）
- **燥土印不化杀**（v5.3）：金日主生未/戌月，七杀格靠印化杀 → 判破格（印虚浮）
- 输出 `establishConditions` 成格条件清单（逐项 ✅❌）+ `breakReasons`

### 从格覆盖（v5.4，4275–4292）

**从格成立时，格局直接返回从格名**（如从儿格·成格），不再显示月令正格；备注「原局XX格·破格，既成从格，以从格论」；`congGe:true`、`basePattern` 保留原局。

## 3. 喜用忌神（`getYongJi` 4516–4738）

### 判定顺序（互斥）

1. **从格优先**（4531–4544）：喜忌完全按从格覆盖（见 §4），method=「从格顺势」
2. **扶抑**：身强 → 喜克泄耗（官杀/食伤/财），忌生扶（印比）；身弱 → 喜生扶（印比），忌克泄耗；中和按分数倾向（<50 喜生扶）
3. **穷通宝鉴特例**（4563–4569）：金日主生未/戌燥土月且身弱 → 弃土取水为用（先用壬水次取庚金），喜水金，忌火木土
4. **调候修正**（4588–4677）：见 §5
5. **格局微调**（4696–4716）：只往 reasoning 加话术（如"官多变鬼"），**不改列表**
6. **生克链**（bazi-chain.js）：只加提示/建议标注，不改分不改列表

### 输出结构（`finalizeYongJiResult` 4311–4416）

- **用神只保留 1 个**（`normalizeYongJiLists` 4297：`yongShen.slice(0,1)`，其余并入喜神）
- `method`：从格顺势 / 扶抑为主·调候辅助 / 格局救应 / 扶抑为主
- 输出：`yongShen[]`（1个）、`xiShen[]`、`jiShen[]`、`primaryReason`、`evidence[]`（旺衰/调候/格局/根气透干四类证据）、`elementReasons`、`patternStatus`、`yongShenQuality`
- 不变量：喜忌无交集；缺什么五行 ≠ 补什么五行（纯扶抑+调候，不做五行平衡）

## 4. 从格判定（`getCongGe` 4873–5009）

### 从强格（日主极强 ≥85）

要求：官杀/食伤力量 ≤1、日支非克泄耗、**全部藏干**无克泄耗 → 喜印比，忌克泄耗

### 从弱格前提（canCong，全部满足）

1. 旺衰=极弱（<30 分）
2. 日支藏干无日主之根或印根
3. 天干无印无比劫（日干自身除外）
4. 地支**本气**无印无比劫（中气余气不算——深藏不透不破格）

### 类型判定（按顺序，命中即返回）

| 类型 | 条件 | 喜 | 忌 |
|------|------|-----|-----|
| 从杀格 | 官杀力量 ≥6 且 ≥ 日主×2 | 官杀、财 | 印、比劫 |
| 从财格 | 财力量 ≥6 且 ≥ 日主×2 | 财、食伤、官杀 | 印、比劫 |
| 从儿格 | 食伤力量 ≥6 且 ≥ 日主×2 | 食伤、财 | 印 |
| 假从势格 | 克泄耗总量 ≥ 生扶总量×2 | 官杀、财、食伤 | 印、比劫 |

（力量统计：天干 +2/字，地支 +1/字，只按本气五行）

### 注意

- 从格喜忌与扶抑**完全相反**
- 十二长生根（如癸水长生在卯）**不参与**从格破格判定——判定只看藏干本气

## 5. 调候（两层，注意区分）

### A. 旺衰⑥调候（2317–2376）——改分

夏冬寒暖燥湿对旺衰分的修正（见 §1 表⑥），直接影响身强身弱分数。

### B. v4.2 喜用调候（4588–4677）——只改列表、不顶用神

《穷通宝鉴》11 组月令×日主组合，每组合把调候五行**从忌神移入喜神末位**（`tiaoHouAdd`）：

- 冬土丑月→火 / 冬火亥子丑→木火 / 冬水亥子→火 / 夏火巳午未→水
- 冬木亥子丑→火 / 秋金申酉戌（身强）→火 / 辰月湿土（土火水日主）→火
- 戌月燥土（火土日主）→水 / 冬金亥子丑→火 / 巳午月燥土（火土日主）→水 / 未月燥土（火土日主）→水

**v4.2 铁律：调候永不顶替用神**——用神由扶抑/格局确定，调候只入喜神末位+出忌神；method 记作「扶抑为主·调候辅助」。
