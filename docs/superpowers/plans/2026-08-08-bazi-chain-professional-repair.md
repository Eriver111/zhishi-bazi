# 八字生克链专业修复实施计划

**目标：** 修复生克链运行、专业判断和岁运归因错误，并建立可重复验证的专业回归测试。

## 任务一：建立真实运行契约

- 新建 `tests/bazi-chain-professional.test.js`，在与浏览器一致的 VM 环境加载 `bazi.js` 和 `bazi-chain.js`。
- 先验证现状因 `window.WU_XING` 失败，再让脚本只读取 `BaZiCalculator` 公共接口。
- 加入无效命盘输入测试和明确错误信息。

## 任务二：修复原局结构判断

- 先写四季、动态杀印文案、藏干根气和库藏十神测试并确认失败。
- 修正 `monthZhi`、四季映射、动态十神与动态干支文案。
- 根气覆盖全部藏干，按藏干位置描述强弱，不重复修改旺衰分。
- 删除无人消费的结构加分字段。

## 任务三：修复岁运判断

- 先写三刑补齐、整柱伏吟、支重复、合局喜忌测试并确认失败。
- 只有当前岁运实际新增关键支时才输出“补齐”。
- 伏吟要求干支同时相同；合与三合根据喜忌输出，不自动加机会分或降低忌运等级。
- 降低确定性措辞。

## 任务四：集成与验证

- 更新页面脚本版本号，避免旧缓存。
- 运行生克链专项、八字专业专项、语法检查和完整测试。
- 用本地结果页验证真实命盘能够产生生克链证据且没有控制台异常。
- 只提交生克链、必要集成、测试和文档文件；不修改支付系统。
