# 手机端首页山水背景重构设计

## 目标

只优化宽度不超过 600px 的首页竖版背景，解决当前手机首屏中段留白过多、画面层次不足的问题。桌面横版背景、首页文字、按钮、导航、功能卡片和交互逻辑均保持不变。

## 方案比较

1. **只用 CSS 放大现有竖图**  
   改动最少，但会重新裁掉顶部松枝和底部远山，只是把“空”换成“局部过大”，不采用。
2. **编辑现有竖图，重新分配山水位置（首选）**  
   保留已确认的宣纸色、淡墨质感和整体气质，同时把远山提高、补充淡云与中景，最容易与桌面版保持统一。
3. **全新生成同风格竖图（备选）**  
   当编辑结果出现拼接感、笔触不统一或主体位置无法满足安全区时启用。构图约束与首选方案相同。

## 视觉构图

- 画布比例为 2:3，最终项目资源为 1024×1536。
- 顶部左侧松枝向画面中央延伸，但不进入标题核心区域；右上保留淡远山，与松枝形成平衡。
- 标题、说明文字和两个按钮所在的中央区域保持低对比宣纸底色，不能出现高对比山峰、树干或金色斑点。
- 在按钮下方加入非常淡的横向云气或水墨层次，连接上方文案与下方远山。
- 底部远山整体提高，使主要山脊约从画面高度的 68% 开始出现，并逐渐向下加深，但不得出现黑色或深灰色横带。
- 保留暖米白、淡赭、灰墨和少量旧金色颗粒；整体明亮、克制、古雅。
- 不出现人物、建筑主体、文字、印章、徽标、水印或现代元素。

## 生成与筛选

- 第一轮以当前 `zhishi-hero-ink-mobile-v2.png` 为编辑目标，尽量保持纸张纹理和笔触一致。
- 若编辑结果不自然，则根据同一构图约束生成全新版本。
- 只选用一张最终图进入网站；未选版本不接入页面。

## 接入方式

- 最终图保存为新的版本化资源：
  - `images/zhishi-hero-ink-mobile-v3.png`
  - `images/zhishi-hero-ink-mobile-v3.webp`
- 首页 `<picture>` 的手机端 `source` 只切换到 v3；桌面端 v2 文件和回退文件全部保留。
- 继续使用已经修复的手机端 `object-fit: cover` 规则，不恢复平移动画和深色水面渐变。

## 验证标准

- 在 390×844 与 430×932 两种手机视口检查首屏。
- 标题、说明和按钮清晰可读，背景不与文字争夺注意力。
- 按钮下方不再出现大面积纯纸纹空区，远山和云气形成连续层次。
- 页面底部不出现黑色横带，手机图不以原始像素尺寸裁切。
- 桌面端仍加载原有横版图，视觉和动画保持不变。
- 自动测试覆盖手机资源路径、响应式缩放和桌面资源不变，并运行完整测试集。

## 回退

旧版 `zhishi-hero-ink-mobile-v2.png/.webp` 保留在仓库中。若新图实际体验不理想，只需将手机端 `source` 改回 v2，不需要回退其他 UI 修改。
