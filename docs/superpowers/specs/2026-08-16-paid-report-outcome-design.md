# 付费报告事实推演与大白话结论设计

日期：2026-08-16  
状态：用户已确认设计方向，等待规格复核  
适用范围：八字深度报告中的财运、学业、今年运势、近五年走势，以及这些栏目引用的婚恋岁运结论

## 1. 目标

将现有付费报告从“关键词解释和行动建议”升级为“由冻结命局事实推演出的现实结论”。报告内部继续使用身强弱、格局、喜用忌、十神、关系事件、结构风险、大运和流年数据；用户页面只显示简短专业来源与通俗结果。

本次成功标准：

1. 财运直接说明财富量级、承载能力、赚钱路径、留存能力和财库状态，不输出理财建议。
2. 学业直接说明可达到的学历层级、学习能力类型、擅长方向和明确短板，并严格受有效结构与反向条件约束。
3. 今年运势和近五年走势不显示任何 1—10 分数。
4. 每个年度同时分析流年、大运对原局四柱的引动，并分析流年与大运之间的关系。
5. 天干生克、天干五合、地支刑冲害合、三合、半合、三会、半会、伏吟及合化条件均进入事实层，不因名称直接判吉凶。
6. 吉凶方向必须结合本命喜神、用神、忌神、被引动柱位和真实生克方向确定。
7. 页面不出现内部字段名、英文枚举、证据数组、算法分数或“建议、应该、优先、宜”等行动性表达。

## 2. 非目标与约束

1. 不修改已经冻结的身强弱、格局、喜神、用神、忌神核心算法。
2. 不修改支付、订单、会员、积分、AI 接口或 PDF 下载流程。
3. 不让 AI 重新计算命局；所有结论必须由本地事实层先确定，AI 只可在其他流程中解释既有事实。
4. 不把传统命理推演包装成现实保证。每个栏目保留简短免责声明，但免责声明不能代替具体判断。
5. 不为缺少出生日期的四柱直排伪造大运；此类命盘只展示流年对原局的引动，并明确未纳入大运。
6. 不把神煞单独作为学历、财富或事件结论的决定条件。

## 3. 总体架构

本次只扩展 `js/deep-report.js` 的报告事实层和叙事层，不改变核心计算器。

数据流固定为：

```text
冻结核心事实
  身强弱 / 格局成破 / 喜用忌 / relationEvents / structuralRisks
        ↓
付费报告领域事实
  财富事实 / 学业事实 / 婚恋事实 / 岁运关系事实
        ↓
方向裁决
  被引动对象 + 关系类型 + 真实方向 + 喜用忌 + 成化状态
        ↓
用户叙事
  专业来源短句 + 现实结果大白话 + 免责声明
```

页面渲染继续使用同一份 narrative 对象，网页与 PDF 复用相同 DOM，避免两处文案不一致。

## 4. 通用叙事契约

每条用户可见结论使用以下结构：

```js
{
  title: '感情稳定基础被打乱',
  sourceText: '流年申冲日支寅，寅木为本命用神。',
  outcomeText: '这一年两个人更容易争吵、分开住、聚少离多，或者重新考虑这段感情是否继续。',
  basis: ['内部稳定证据键，不展示给用户']
}
```

展示顺序固定为：

1. 标题：直接说结论。
2. 专业来源：一至两句，允许出现流年、大运、柱位、十神、刑冲合害和喜用忌。
3. 现实结果：使用普通用户能理解的行为、处境和感受描述。

禁止只显示“结构受损、能量变化、议题增强、消耗、失衡、暗耗、承接不足”等抽象词。出现专业词后必须立即解释现实表现。

## 5. 岁运关系事实层

### 5.1 分析对象

每个报告年度分别建立以下关系：

1. 流年干支对原局年柱、月柱、日柱、时柱。
2. 当前大运干支对原局年柱、月柱、日柱、时柱。
3. 流年干支与当前大运干支。
4. 流年或大运加入原局后形成的三合、半合、三会、半会及三刑补齐。

每条关系记录：来源、目标柱、天干或地支、关系类型、作用方向、涉及五行、形成五行、形成五行的喜用忌、是否满足成化证据、用户领域和最终方向。

### 5.2 必须覆盖的关系

天干：

- 同气、相生、相克，并记录谁生谁、谁克谁。
- 甲己、乙庚、丙辛、丁壬、戊癸五合。
- 五合只记录“相合”或“达到成化条件”，不能看到五合就直接写成化。

地支：

- 六冲、六合、六害、刑、伏吟。
- 三合、半合、三会、半会。
- 三刑补齐。
- 已有权威接口能够返回的其他明确关系。

### 5.3 合化门槛

“合”与“化”必须分开：

1. 只有相合关系而无成化证据时，写“合住、联系增强或被牵住”，不得写成五行已经改变。
2. 三合、三会或五合达到权威事实层的成化条件时，才记录 `transformed=true`。
3. 半合、半会只记录气势趋向，绝不等同完全合化，也不等同暗合或隐秘关系。
4. 成化后的吉凶按形成五行在冻结喜用忌中的角色判断。

### 5.4 方向裁决

关系名称不直接等于吉凶，采用以下顺序：

1. 先确定被引动的原局柱位和五行角色。
2. 再确定流年或大运五行的角色。
3. 再看真实作用方向。
4. 最后结合形成五行和结构风险给出结论。

基本裁决：

- 冲喜神或用神：原有帮助和稳定基础被打乱，方向偏不利。
- 冲忌神：旧有压力可能被打破，方向可偏有利，但“冲”带来的变化、争执、迁移或中断仍须写出。
- 合成喜神或用神：联系、资源或稳定作用增强，方向偏有利。
- 合成忌神：被拖住、反复纠缠、责任或压力聚集，方向偏不利。
- 只合不化且目标为喜用：可能把有利力量合住；结合方为忌时偏不利。
- 只合不化且目标为忌：不自动判好；可能表现为压力被长期黏住。
- 刑、害：保留摩擦、反复、不信任和隐性矛盾的性质。即使涉及忌神，也不能机械写成好事。
- 伏吟：放大原有状态。原位为喜用时放大帮助，原位为忌时放大旧问题。
- 相克：必须按“谁克谁”裁决。喜用力量克制忌神可偏有利；忌神克制喜用偏不利；原局喜用反克岁运忌神表示能抵抗压力，但仍存在消耗。

无法形成单向结论时显示“会发生明显变化，但现有事实不能确定最终变好或变坏”，不得强行定吉凶。

### 5.5 柱位与现实领域

- 年柱：早年环境、长辈、外部圈层和社会环境。
- 月柱：工作环境、组织关系、家庭基础和当下事业节奏。
- 日干：本人状态与决策。
- 日支：伴侣、亲密关系、共同生活和个人落脚点。
- 时柱：长期计划、项目成果、下属晚辈与后续发展。

柱位只决定现实落点，不单独决定吉凶。

## 6. 财运报告

### 6.1 保留内容

保留 A1—A10 财富量级，含义沿用已确认口径：A1 为 1 元级、A2 为 10 元级，依次递增至 A10 为 10 亿元级。等级表示命局可承载的个人净资产峰值参考，不代表当前存款或收益承诺。

### 6.2 推演维度

1. 财星是否透干、藏支、有根、有生源或受制。
2. 身强弱和从格决定能否担财。
3. 财星属于用神、喜神还是忌神。
4. 格局和有效链决定主要赚钱方式，例如食伤生财、财生官、财配印、比劫参与。
5. 比劫争财、财破印、财党杀等结构决定财富分流或压力。
6. 财库是否真实包含财星，是否被冲、刑、合或岁运引动，以及财库对应五行的喜忌。
7. 流年和大运是否引动财星、财库、财富路径或财富风险。

### 6.3 用户结论

用户必须看到：财富大致量级、钱主要从哪里来、能不能承担更大收入、钱能不能留下、资产是否容易沉淀，以及最容易发生财富变化的年份。

删除储蓄、配置、合同、控制投入、选择行业等建议性内容。将其改写为命局事实，例如“收入增加以后仍容易被合作分配或责任支出带走”。

## 7. 学业报告

### 7.1 输出内容

1. 直接给出学历层级，例如“完成本科相对顺”“本科有机会但过程吃力”“传统应试较吃力，技能型学习更容易出结果”。
2. 给出学习类型：不厌其烦用功型、聪明行动型、灵感突破型、聪明且努力型、逻辑理性型、文采思想型或普通复合型。
3. 给出更容易发挥的领域。
4. 给出真实短板如何表现，不提供学习建议。

### 7.2 正向结构优先级

只有满足实际十神、有效格局、喜用忌与阻断条件时才生效：

1. 杀印相生且成格，印为用神或喜神：最高级的长期用功型，七杀压力经印转为吸收与持续投入；高于官印相生。
2. 官印相生且成格，印为用神或喜神：规则承接、长期学习和标准化考试较强，但层级低于有效杀印相生。
3. 比劫多、印确属忌且旺、同时存在权威“财制印”链，财为用神或喜神，且无财破印/财坏印：聪明并具有行动转化能力。这里必须修正现有“印为忌即阻断财制印”的冲突口径。
4. 羊刃结构、身旺或极旺、印有实际强证据，同时食神或伤官形成有效吐秀且不为忌：灵感突破型。不能只因出现羊刃和一个食伤就成立。
5. 官杀旺相且有有效食伤制化：聪明且努力型。内部优先级为食神制杀，高于有权威关系证据的伤官合杀，高于食神克正官。伤官见官不得混入正向结构。
6. 金水相涵：金水均有有效出现，形成连续生化，且无燥烈或寒湿失衡证据时，判为逻辑、理性、分析型，数理、金融、法律等方向更容易发挥。
7. 木火通明：木火均有有效出现，形成连续生化，且无燥烈、火炎木焚或木火偏枯证据时，判为文采、思想、艺术、教育型。

金水相涵和木火通明采用严格门槛。若调候、月令或冻结事实显示过寒、过燥、过烈，不得触发强结论。

### 7.3 反向条件

1. 印星为忌且有“印旺、印成势”的权威证据：容易反复思考、依赖既有答案、收集很多但转化慢。不能仅凭印星数量判旺。
2. 食伤过旺无制：容易贪玩、反规则、注意力分散或只愿做感兴趣的内容。必须有旺而无制证据。
3. 财破印或财坏印：学习阶段更容易被赚钱、感情、娱乐或现实事务打断。
4. 身弱或极弱、官杀旺而无印：规则和考试压力更容易压垮持续性，遇到高压阶段容易放弃。
5. 用神无力或空亡：只有权威事实明确指出用神无根、受制或落空亡时才采用；不得根据“原局没有该五行”机械推断。
6. 格局破格、关键链被冲克或喜用力量受损时，正向结构必须降级。

正向和反向条件同时出现时，先展示主要优势，再明确写出它会在哪里失效；学历层级按受损后的结果输出。

## 8. 今年运势

完全移除 1—10 分、等级标签和“节奏可控”等泛化结论。

展示结构：

1. 本年总判断：由流年、大运的喜用忌和实际引动综合得出。
2. 专业来源：列出最关键的两至四条岁运关系。
3. 现实结果：分别说明事业、财富、感情、学业及确有证据的身心压力表现。
4. 若无明确触发，直接写“本年主要延续原有状态，没有足够依据断定重大变化”，不填充套话。

## 9. 近五年走势

完全移除五年平均分、每年分数、“最高分年份”和“最低分年份”。

每年显示：

1. 流年干支和所在大运。
2. 一至三条最关键的专业来源。
3. 该年最明确的现实变化。
4. 方向标签仅允许“偏有利、偏不利、变化明显、延续为主”，不得显示算法分数。

五年总览直接说明：哪一年更容易兑现、哪一年变化最大、哪一年旧问题最容易被引动，以及大运切换发生在哪一年。没有足够差异时如实说明五年间没有明显高低峰。

## 10. 去建议化规则

用户可见 narrative 中禁止出现以下措辞：

- 建议、应该、应当、优先、最好、宜、需注意、需要做到。
- 适合把目标拆分、建立计划、控制投入、寻求支持等行动指令。

允许出现：

- “更容易……”“通常表现为……”“这张命盘显示……”“该年会把……引动”。
- 为防止虚假确定性而使用的“现有事实不能确定”“不等于必然发生”。

内部 facts 和旧式降级卡片可以暂时保留事实性条件，但付费 narrative 不读取建议文案。

## 11. 渲染与兼容

1. `reportNarrative` 支持没有评分条的今年运势、婚姻和五年走势。
2. 财运继续显示 A 级；学业显示学历层级，可保留内部 L 级但用户不依赖 L 数字理解结论。
3. 年度 verdict 支持分别渲染 `sourceText` 和 `outcomeText`；旧 `text` 字段在迁移期间保留兼容。
4. HTML 转义继续覆盖标题、专业来源、现实结果和免责声明。
5. PDF 从页面已渲染区域克隆，保证内容一致。
6. 更新静态资源版本，防止线上缓存继续显示旧报告。

## 12. 测试与验收

### 12.1 学业专项盘

至少覆盖：

1. 杀印相生成格且印为用，输出高于官印相生的层级与“不厌其烦用功型”。
2. 官印相生成格但存在破格或印为忌，必须降级。
3. 印为忌且旺、财为喜用并有权威财制印，输出“聪明且行动力强”。
4. 财破印与财制印不得互相误判。
5. 羊刃、印旺、食伤吐秀缺少任一门槛均不得输出最高灵感型。
6. 食神制杀、伤官合杀、食神克官按优先级区分；伤官见官不得判成正向制化。
7. 金水相涵、木火通明各有一条成立盘与一条寒燥反例。
8. 食伤过旺无制、身弱杀旺无印、财坏印、用神无力或空亡分别触发降级。

### 12.2 岁运专项盘

至少覆盖：

1. 流年冲喜用夫妻宫，输出具体不利变化。
2. 流年喜用冲忌神夫妻宫，输出打破旧压力但仍有变化成本。
3. 六合形成喜用五行与形成忌神五行得到相反结果。
4. 只合不化不写成化。
5. 半合不写成完全合化或暗合。
6. 刑、害不因目标为忌神而自动判好。
7. 天干相克按真实方向区分。
8. 流年、大运分别引动原局四柱，并去重显示。
9. 流年与大运天克地冲、岁运并临和大运切换能够进入年度结论。
10. 四柱直排无出生日期时不伪造大运。

### 12.3 渲染验收

1. 今年、婚姻和五年无评分条；财运仍有 A 级。
2. 页面与 PDF 中不出现内部英文和原始字段名。
3. 用户可见四个优化板块不出现建议性禁词。
4. 每条重要岁运结论先显示专业来源，再显示大白话结果。
5. 桌面端和手机端均无横向溢出，长句正常换行。
6. 真实示例页至少验收一盘包含半合、天干五合、流年冲夫妻宫及五年大运的命盘。
