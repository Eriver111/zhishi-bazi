# 风水功能 · 设计规格书

## 概述

基于《图解八宅明镜》知识库，新增风水分析页面。用户输入房屋坐向 + 格局方位标注 + 房间照片，AI 结合八宅法进行吉凶分析。

## 输入流程（四段式）

### 第 1 步：定坐向
- 罗盘风格 UI，8 个方位按钮（东/南/西/北/东南/东北/西南/西北）
- 选中后显示"坐X朝Y"
- 进阶：可展开 24 山细分

### 第 2 步：标格局
- 3×3 九宫格方位示意图
- 4 个下拉：大门、主卧、厨房、卫生间各在哪个方位
- 可选补充：客厅、书房、阳台方位

### 第 3 步：拍照片（4 张必传 + 1 张选传）
- 大门照（必传）："站在门外正对大门拍摄"
- 客厅照（必传）："站在客厅入口处拍摄整个空间"
- 厨房照（必传）："站在厨房门口向内拍摄灶台和水槽"
- 主卧照（必传）："站在卧室门口拍向窗户和床"
- 户型图（选传）："上传户型图可大幅提升分析精度"

### 第 4 步：看结果
- 墨卷舒展动画展示
- 内容：宅卦判定 → 各方位吉凶（九星分布）→ 照片形煞分析 → 综合建议

## API 设计

```
POST /api/fengshui-reading
{
  sitting: "北", facing: "南",
  layout: { door: "东南", masterBedroom: "西南", kitchen: "北", bathroom: "东" },
  images: [{ slot: "door", data: "base64..." }, ...]
}
→ { reading, creditsLeft, isMonthly }
```

有图时 2 轮 AI 调用（各图独立分析 → 汇总），无图时 1 轮（纯方位分析）。
积分：月度会员免费，普通用户扣 1 次。

## 复用模式

完全沿用 face.html/palm.html 的前端动画、API 结构、积分系统、MaaS 降级逻辑。
