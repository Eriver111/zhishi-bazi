# 八字深度报告 v2 设计规格

日期：2026-08-15  
状态：已获用户确认，待实施计划  
范围：八字结果页五个付费栏目  

## 1. 目标

把现有五个付费栏目从“十神数量与固定关键词拼接”升级为“基于冻结命局事实的分领域推演”：

1. 今年运势参考；
2. 感情婚姻参考；
3. 财运分析参考；
4. 学业发展参考；
5. 五年流年详批。

本次不修改已经冻结的旺衰、格局、从格、喜用忌、合化和结构风险判定。核心引擎负责判断，深度报告负责按领域组织、解释和展示判断，不允许报告层自行重算核心结论。

## 2. 不在本次范围

- 不修改支付金额、二维码、支付回调、订单轮询、积分、会员或已购权限判定。
- 不改变结果页五个付费栏目的 DOM 标识和付费遮罩框架。
- 不新增深度报告 AI 请求，不增加模型费用、超时和空回复风险。
- 不重写八字核心算法，不为报告需求反向修改冻结结论。
- 不承诺现实财富金额、婚期、学历、疾病或灾祸。

## 3. 总体架构

采用“统一事实层＋本地专业模板”方案。

新增独立浏览器模块 `js/deep-report.js`，消费现有公开能力：

- `BaZiCalculator`：四柱、藏干、十神、旺衰、格局、喜用忌、从格、大运、流年；
- `StructuralAnalysis`：`relationEvents` 与 `structuralRisks`；
- `BaZiChain`：原局生克链、岁运作用链与库藏引动提示。

新模块不得覆盖或修改以上对象的输出。旧 `analyzeWealth()`、`analyzePei()`、`calculateSpouseAge()`、`analyzeStudy()`、`analyzeThisYear()`、`analyzeFortune()` 暂时保留供兼容，但五个付费栏目不再以它们的旧结论作为权威来源。

统一入口：

```text
DeepReport.buildFacts(bazi, gender, options)
```

统一输出：

```text
deepReportFacts
├─ schemaVersion
├─ anchorYear
├─ chartIdentity
├─ core
│  ├─ strength
│  ├─ pattern
│  ├─ yongJi
│  ├─ congGe
│  ├─ actionChains
│  ├─ relationEvents
│  └─ structuralRisks
├─ wealth
├─ relationship
├─ study
├─ currentYear
└─ fiveYear
```

每条领域结论使用统一证据结构：

```text
{
  conclusion,
  evidence[],
  confidence,       // strong | medium | limited
  conditions[],
  elementRole,      // 用神 | 喜神 | 忌神 | 中性，可为空
  pillars[],
  timing            // 大运/流年信息，可为空
}
```

相同命盘、性别、报告年份和事实版本必须产生稳定一致的结果。

## 4. 核心事实使用纪律

1. 旺衰只读 `calcDayMasterStrength()` 的权威结果，不在领域分析中另行打分。
2. 格局及成破只读 `getPattern()`。
3. 喜用忌只读 `getYongJi()`；从格按已冻结结果优先，禁止套普通身强弱话术。
4. `relationEvents` 是客观关系枚举，不单独定吉凶。
5. `structuralRisks` 是条件性风险，不能反向改写喜用忌。
6. 库冲只表示藏干或库气受到引动；不得写成“冲开必发”或“冲开必凶”。
7. 神煞仅作辅助证据，不得凌驾于旺衰、格局、喜忌和结构。

## 5. 财运领域模型

财运定义为命局获取、承载、转化和留存财富资源的结构倾向，不等同于财星数量，也不映射具体人民币金额。

### 5.1 财星质量

- 识别日主所克五行为财，区分正财、偏财；
- 记录透干、藏支、本气/中气/余气、柱位；
- 记录得令、通根、生源和受制信息；
- 记录财星参与的冲、合、刑、害、合化候选；
- 不把所有出现位置按等权“颗数”相加。

### 5.2 承载能力

- 身强且财为喜用：具备较好的资源调动候选；
- 身弱财旺且财为忌：机会和压力并存；
- 身弱但有有效印比支持：说明承载条件有所缓解；
- 从财格成立：按从格顺势解释，不套“身弱不担财”。

### 5.3 财富路径

至少识别并解释：

- 食伤生财；
- 财生官；
- 财官印连续流通；
- 财配印；
- 比劫与财并见；
- 财党杀；
- 财破印。

路径必须引用真实干支、十神和五行，不只返回路径名称。

### 5.4 留存与结构稳定

分别输出获取、转化、留存和风险倾向。比劫分流、财破印、财印冲、财党杀等不得被压缩成一句“财运不好”；必须说明条件、救应和影响范围。

### 5.5 财库

财库规则作为报告层独立事实规则冻结后实现，至少检查：

- 库支中是否真实藏有对应财星；
- 财星是否入库候选；
- 库是否受冲、刑、合等事件引动；
- 被引动之财属于喜、用、忌还是中性；
- 是否有透干、月令或岁运响应证据。

不得用“见辰戌丑未即有财库”的粗规则，也不得以单一库冲断发财。

### 5.6 财运展示

展示五个维度：资源显现、承载能力、获取路径、留存稳定、岁运窗口。顶部仅给“较强、稳健、中等、承压、待时”等综合倾向，并附证据，不显示虚假的财富分数和金额级别。

## 6. 感情婚姻领域模型

采用已确认的传统配偶星口径：男命以财星为主要配偶星，女命以官杀为主要配偶星；夫妻宫（日支）为男女共同核心。文案使用现代、克制语言，不使用“克夫、克妻”等伤害性硬断。

### 6.1 夫妻宫

- 读取日支五行及全部藏干，不只取本气；
- 记录各藏干十神及层级；
- 判断夫妻宫五行的喜用忌角色；
- 检查月令支持、根气和涉及日支的关系事件；
- 检查冲、合、刑、害、破、伏吟及合化候选；
- 区分紧贴、隔柱、涉及月令和是否存在救应。

### 6.2 日干与日支互动

- 日支生日干：伴侣/关系更倾向提供支持；
- 日干生日支：命主更倾向主动投入；
- 日干克日支：命主更倾向主导、管理或提出要求；
- 日支克日干：命主更容易感到关系责任或压力；
- 干支同类：平等、相似，也可能互不相让。

以上只描述互动方向，必须结合喜忌、旺衰和结构，不翻译成“谁一定更爱谁”。

### 6.3 配偶星质量与位置

- 是否出现、正偏、透藏、得令、通根；
- 是否为喜用、忌神或中性；
- 是否清纯或正偏混杂；
- 是否受冲克、合绊、比劫竞争；
- 是否与夫妻宫相互呼应；
- 年、月、日、时柱位置作为认识渠道、远近和出现阶段的候选证据。

位置推断只能输出倾向。年柱可作为生活圈外/背景差异/较早阶段的弱信号；月柱可作为同学同事、工作圈或同城附近的信号；日柱偏身边长期接触；时柱偏较晚阶段、未来生活圈或异地候选。须叠加驿马、关系事件和岁运后才能提高可信度。

### 6.4 年龄倾向

综合配偶星柱位、夫妻宫十神、正偏组合、贴近日主程度和实际姻缘触发的大运。只输出“略年长、相仿、略年轻、证据不足”，不输出确定年龄差或“±5岁”。

### 6.5 外在气质

保留配偶外貌栏目，但改名和降级为“外在气质与形象风格倾向”。综合：

- 日支五行意象；
- 本气及中余气；
- 夫妻宫十神；
- 旺衰、喜忌和冲合状态；
- 配偶星对夫妻宫的校正。

三类可信度：夫妻宫、配偶星、喜忌同向为 `strong`；只有夫妻宫单一信号为 `limited`；信号冲突时直接说明特征不集中。禁止断具体身高、脸型、肤色和身体特征。

### 6.6 稳定性与时间

结合配偶星、夫妻宫、比劫争财、伤官见官、官杀混杂及相关风险，区分原局基础、关系机会、推进、现实安排、调整和边界压力。合夫妻宫不等于必婚，冲夫妻宫不等于必离。

## 7. 学业发展领域模型

学业拆成四类能力：吸收理解、表达输出、纪律应试、实践转化。传统考试适应度不等同于整体学习能力。

### 7.1 印星

判断正偏、透藏、得令、通根、喜忌、日主是否需要印、印是否过重、是否财破印、能否承接官杀。身弱喜印和身强印多为忌必须输出不同结论。

### 7.2 食伤

判断食神的稳定输出与伤官的创新表达，结合日主承载、喜忌和印星调节。伤官见官不得机械写成考试差；需区分标准化环境中的摩擦和研究、创意、技术场景中的优势。

### 7.3 官杀

用于判断规则适应、长期执行、考试认证和压力转化。识别官印相生、杀印相生、官杀过重无印等结构。

### 7.4 格局、风险与辅助星

重点识别印格、官印相生、杀印相生、伤官配印、食神格、财格/食伤生财、建禄月劫的学习出口。消费财破印、伤官见官、枭神夺食、官杀混杂、杀重制化等结构事实。

文昌、学堂等神煞仅作辅助证据，不能单独决定学业等级。

### 7.5 展示内容

展示学习吸收方式、表达与实践能力、纪律应试状态、适合的学习路径、结构障碍和岁运窗口。保留专业/发展方向，但按有效结构推荐研究型、考试型、技术型、创作型或实践型路径，不按五行机械罗列职业，不承诺学历和录取结果。

## 8. 今年运势与五年流年模型

两者共用同一岁运分析器。每个年份按“原局→该年所属大运→流年干支→喜用忌→十神领域→关系事件→风险/救应”独立计算。

### 8.1 大运

- 每个流年查找其实际所属大运；
- 五年跨大运时必须切换，不得将当前大运套用五年；
- 分别读取大运干支的五行、十神、喜忌角色和原局关系；
- 检查大运是否补全成格条件、加强破格原因、触发结构风险或形成救应。

### 8.2 流年干支

天干负责外显透出、天干合克和十神事件；地支负责根气、宫位激活、冲合刑害、三合三会、库藏和伏吟等。干支结论不一致时输出混合状态，不强行归为单一吉凶。

### 8.3 分领域输出

- 事业：官杀、印、食伤、月柱/月令及相关结构；
- 财运：调用财富领域模型；
- 感情：调用姻缘领域模型；
- 学业：调用学业领域模型；
- 身心状态：只输出压力、作息、活动、饮食和情绪管理提醒，不作疾病诊断。

### 8.4 风险触发

原局 `structuralRisks` 不得每年机械复制。只有当岁运加强风险一方、削弱救应或直接引动相关节点时才提高提示；岁运补入救应时应明确说明缓和。

### 8.5 五年趋势

先逐年独立计算，再比较五年，识别准备、机会显现、结构调整、成果兑现、节奏收敛等候选阶段。标签由事实生成，不预设轮流出现；突出跨大运、连续增强和单年短暂触发。

## 9. 报告年份快照

深度报告的“今年＋未来五年”固定为购买年份，不随以后打开时间滚动。

- 登录用户：使用报告记录 `paid_at` 的中国时区年份；
- 新游客：为命盘报告单独保存首次解锁年份；
- 历史登录报告：由既有 `paid_at` 补足，无数据库迁移；
- 历史游客：旧本地记录没有购买时间，首次在新版打开时锁定当年，之后保持；
- `anchorYear` 不加入命盘身份、订单哈希或付费权限键。

必要时报告访问接口可只读返回 `paid_at`，但不得改变支付创建、回调、轮询和履约行为。

## 10. 四柱直排降级规则

若四柱排盘已经匹配并由用户选择具体出生年月日时，可正常计算起运、大运和五年流年。

若只有四柱与性别、没有确认出生日期：

- 原局、财富、姻缘、学业可正常生成；
- 流年与原局关系可正常生成；
- 不定位当前大运，不伪造起运年龄；
- 报告明确标注“未确认出生时间，当前大运未纳入”；
- 相关结论可信度相应降低。

## 11. 文案确定性边界

### 11.1 可明确陈述

四柱、十神、藏干、旺衰分数/档位、格局成破、喜用忌、已枚举关系、确定的大运流年干支。

### 11.2 只作倾向陈述

财富获取和留存、配偶年龄远近和外在气质、学习方式、岁运机会和调整。

### 11.3 禁止确定性陈述

具体财富金额；必然发财/破财；必然结婚/离婚；配偶具体身高脸型年龄差；必然取得学历；疾病诊断、器官病变、灾祸和死亡。

## 12. 页面、PDF与兼容

- 保留现有五个 section ID 和顺序；
- 保留付费遮罩、解锁和报告库入口；
- 页面和 PDF 读取同一已渲染事实，不各自重算；
- 不大改结果页总体布局，只优化栏目内部证据层级和可读性；
- 新模块失败时显示明确的“专业报告暂时无法生成”，不得静默回退到可能冲突的旧结论；
- 旧函数暂不删除，以降低其他入口回归风险。

## 13. 验收标准

1. 冻结核心文件和权威输出零漂移；
2. 同命盘、同性别、同报告年份重复生成结果一致；
3. 财运不再自行计算旺衰，不再输出金额承诺；
4. 男女命配偶星选择正确，夫妻宫生克方向正确；
5. 年龄、远近、外在气质均具多证据与可信度；
6. 学业同时消费印、食伤、官杀、格局、喜忌与结构风险；
7. 文昌、学堂不能单独决定学业等级；
8. 每个流年匹配实际大运，跨运五年正确切换；
9. 结构风险只在触发条件满足时升级；
10. 报告重开仍使用购买年份；
11. 四柱无出生时间时安全降级；
12. 页面和 PDF 内容一致；
13. 全文不出现财富、婚姻、学历和健康硬断；
14. 支付相关文件无改动，支付测试结果不发生新增失败；
15. 现有结果页免费区、AI 对话、报告库和海报功能无新增回归。

## 14. 实施顺序

1. 建立统一核心事实与年份快照；
2. 第一批实现财富、今年运势、五年流年；
3. 验证跨大运、财库和风险触发；
4. 第二批实现婚姻与学业；
5. 接入结果页和 PDF；
6. 运行专项、全量与支付隔离测试；
7. 本地真实命盘抽测并由用户体验；
8. 全部通过后统一提交，是否推送由用户另行决定。
