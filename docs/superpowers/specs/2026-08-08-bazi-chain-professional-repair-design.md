# 八字生克链专业修复设计

## 目标

让 `js/bazi-chain.js` 在浏览器中真实运行，并将其定位为“结构证据与岁运触发分析器”。个人排盘的旺衰、格局、喜神、用神、忌神仍以 `js/bazi.js` 的专业事实对象为唯一权威，生克链不得暗中改写这些核心分类。

## 接口与数据流

- 生克链只通过 `window.BaZiCalculator` 获取五行、藏干和十神，不依赖未导出的全局常量。
- `analyze(bazi)` 返回结构提示、建议性标注、天干链和地支链；异常必须可测试，调用方不得用空结果伪装成功。
- `analyzeFortune` 与 `analyzeLiuNian` 只描述已满足条件的岁运触发，不把单一冲合直接等同于吉凶结果。
- `bonuses.structural` 不再保留为无人消费的伪分数；杀印相生只进入证据，不重复修改旺衰分。

## 专业规则

- 四季固定为寅卯辰春、巳午未夏、申酉戌秋、亥子丑冬。
- 杀印相生文案从真实月支、月干、日支及藏干动态生成，并区分正官、七杀、正印、偏印。
- 根气检查覆盖本气、中气、余气，区分强根、普通根、余气根；文案使用真实日主五行。
- 库冲属于流派规则：仅标记“藏干被引动/库气变化”，不直接宣称一定开库、一定吉或一定凶；十神名称按当前日主动态计算。
- 三刑必须由当前大运或流年补齐才称“补齐”；原局或原局加大运已成立时不得归因给无关流年。
- 整柱干支相同称伏吟；仅地支相同标记为“地支重复”，不冒充整柱伏吟。
- 天干合、地支合不预设为吉，三合成局也必须结合所成五行的喜忌判断。

## 文案安全

结论使用“提示、倾向、容易触发”等概率表达。删除与实际命盘无关的写死干支、必然事故、必然官非和“必有大变”等确定性措辞。

## 验证

- Node 行为测试覆盖浏览器接口、四季、杀印、根气、库冲、三刑、伏吟、合局喜忌和无输入防御。
- 既有八字专业测试与完整测试不得新增失败。
- 本地结果页确认 `chainHints` 非空且控制台无生克链异常。
