# 八字喜用忌与深度报告专业化设计

日期：2026-08-01

## 目标

在不改变现有结果页主框架、支付解锁、报告库、PDF 下载和海报功能的前提下，重构喜用忌的判定顺序与结构化依据，并让 JS 生成的深度报告能呈现完整、可追溯的命理推理链。

## 明确保留

- 不改写现有财富金额文案。
- 不改写现有健康确定性文案。
- 不增加“闲神”“仇神”等新分类。
- 本轮不推送远端、不部署上线。

## 喜用忌输出口径

用户可见层只保留三类：

1. **用神**：对当前命局最关键的五行，对外只保留 1 个核心用神；其他有利五行统一归入喜神，不再并列为第二用神。
2. **喜神**：对命局有助的五行集合。按用户确认的 B 口径，用神属于喜神中的核心，因此允许用神同时出现在喜神列表中。
3. **忌神**：会加重命局失衡或破坏已有制化关系的五行。忌神必须与喜神、用神互斥。

五行未出现只是客观分布信息，不直接导出“需要补该五行”。

## 统一判定顺序

`getYongJi()` 是全站唯一喜用忌事实源，固定按以下顺序判定：

1. **从格优先**：若 `getCongGe()` 确认从格，直接按顺势取用，不再套普通扶抑。
2. **调候急迫性**：寒、暖、燥、湿达到明显偏枯时，调候五行可成为首用，但必须记录触发月令与原局依据。
3. **旺衰扶抑**：根据统一的 `calcDayMasterStrength()` 结果确定生扶或克泄耗的基本方向。
4. **格局成破**：结合 `getPattern()` 的候选格局、成格/破格状态和原因，检查所取五行是成格、救应还是反而破格。
5. **原局可用性**：检查候选五行在原局中是否透干、通根、受冲克或已有制化。这一层用于确定用神优先级，不凭空新增第四类神。
6. **互斥和稳定化**：去重、保持五行顺序稳定，从忌神中移除所有喜神和用神。同一命盘重复打开必须得到同一结果。

## 结构化数据

保留现有兼容字段：

- `xiShen: string[]`
- `yongShen: string[]`
- `jiShen: string[]`
- `reasoning: string`
- `dayMasterLevel`
- `dayMasterScore`
- `congGe`（命中从格时）

新增专业证据字段：

- `method`：主判方法，如从格、调候优先、扶抑为主。
- `primaryReason`：一句话总结取用核心。
- `evidence[]`：按“旺衰、调候、格局、根气/透干”分组的依据。
- `elementReasons`：按五行记录其被判为用、喜或忌的理由。
- `patternStatus`：格局名、成破状态与破格原因的快照。

这些字段只提供证据，不增加新的喜用忌分类。

## JS 深度报告结构

深度报告继续由前端 JS 确定性生成，不依赖 AI 自由发挥。现有报告区块顺序和解锁机制不变，增强“专业命理分析”内容：

1. **命局总纲**：日主、旺衰等级与分数、候选格局及成破、用神总结。
2. **旺衰依据**：展示得令、得地、得势、调候及合冲修正的有效依据，不另设第二套分数。
3. **喜用忌结论**：只呈现用神、喜神、忌神；每个五行后说明作用机理。
4. **格局成败**：成格列成立依据；破格保留格局名，列主要破格原因和可能的制化方向。
5. **原局作用链**：从已计算的十神、透干、根气、合冲刑害中提取最关键的 2–4 条关系，如官印相生、食神制杀、财星破印。
6. **岁运联动**：大运或流年遇到喜用、忌神时，指出它触发的原局关系，不只输出“吉/凶”。

财运与健康的现有文案区块原样保留，但它们可继续读取修正后的基础盘面数据。

## 数据流与兼容

1. `js/bazi.js` 生成格局、旺衰、喜用忌和专业证据。
2. `js/result.js` 和 `js/pro-analysis.js` 只负责渲染，不重新计算喜用忌。
3. PDF 继续复制页面已渲染的报告区块，因此与网页结论保持一致。
4. AI 上下文继续传入 `xiShen/yongShen/jiShen` 及新的证据字段，不允许 AI 另行改判。
5. 保留现有字段名，不破坏历史报告、已保存的本地数据和现有测试。

## 异常与边界

- 从格与普通扶抑结论相反时，以从格结果为准并明确说明“顺势取用”。
- 调候与扶抑相反时，只有达到调候急迫条件才能提升为用神，并记录原因。
- 中和命局不仅依赖 50 分上下机械分流，必须结合月令、格局成破和调候确定首用。
- 若证据不足，保留“需结合岁运复核”的依据提示，但不新增用户可见分类。
- 所有五行列表必须去重，且忌神不得与喜神或用神重叠。

## 验收标准

- 用户可见的喜用忌区域只出现“用神、喜神、忌神”。
- 用神允许同时属于喜神；忌神与两者不重叠。
- 从格、偏强、偏弱、中和、调候急迫、成格和破格均有固定命例测试。
- 深度报告展示命局总纲、旺衰依据、喜用忌依据、格局成败、原局作用链和岁运联动。
- 结果页、深度报告、PDF 和 AI 上下文对同一命盘的三类结论一致。
- 财富金额文案和健康确定性文案经文本对比确认未改写。
- 现有全部测试与新增专业命例测试全部通过。
