# 付费报告财富、学业与四柱大运优化设计

日期：2026-08-16  
状态：待用户最终确认后实施

## 1. 目标与边界

本轮只调整深度报告事实组织、用户文案和四柱反查时间在报告中的消费方式，不修改冻结的旺衰、格局、喜神、用神、忌神算法，也不修改支付、AI 接口和 PDF 引擎。

目标：

1. 财富报告不再以五张碎片化卡片罗列事实，而是先形成统一判断，再解释钱从哪里来、能否留下、通过什么条件放大。
2. 增加由本命喜用忌和实际财富通路共同决定的得财方向。
3. 学业只显示高学历、普通学历、低学历三档，并用具体难易程度解释，不使用“大专层级”等带有淘汰感的标签。
4. 四柱反查已经选中出生年月日时后，深度报告必须纳入真实大运；出生时间未知、起运前、已进入大运三种状态必须分开。
5. 所有面向用户的结论使用具体、直接、能立刻理解的大白话，不使用“消耗、纠缠、失衡、结构张力”等抽象术语。

## 2. 财富事实模型

财富结论按以下顺序推演，后一步不得覆盖前一步的事实：

1. **能不能担财**：读取冻结的身强弱、从格与财星喜用忌。
2. **财富机会强不强**：读取财星透藏、月令、根气、生源与受制证据。
3. **钱从哪里来**：读取食伤生财、财生官、财官印、财配印、比劫合作等已确认通路。
4. **钱能不能留下**：读取财库、比劫分财、财破印、财党杀等证据。
5. **有没有突然放大的条件**：综合偏财、财库、强财富通路及岁运引动；不得仅凭“有财库”写一夜暴富，也不得仅凭“无财库”否定所有突发财运。
6. **哪个方向更容易打开财路**：用喜用忌筛选方向，再由真实财富通路解释该方向带来的是客户、平台、合作还是直接财富机会。

### 2.1 库的双层定义

库必须分成两个维度：

- 固定库性：辰水库、戌火库、丑金库、未木库；再按日主换算为财库、官杀库、印库或食伤库。
- 库内藏干：逐个标记正财、偏财、比肩、劫财、印、官杀、食伤及其喜用忌。

不得因为未中本气为己土，就直接把未称为“劫财库”。正确表达示例：

> 未是木库，对你属于官杀库；库中同时藏有劫财、印星和官星。

### 2.2 比肩、劫财的财富裁决

- 比劫为喜用，且存在“比劫→食伤→财”或权威合作生财通路：结论为团队、伙伴或圈层能放大赚钱效率。
- 比劫为喜用，但没有通往财星的证据：只能写有人分担、提供资源或帮忙推进，不能写对方直接带来收入。
- 比劫为忌，或存在比劫夺财/分流证据：结论为合作后更容易争客户、争决定权或分钱，进账增加也可能留不住。
- 库中比劫被冲、刑、合引动时，继续按上述规则裁决，不把“开库”自动视为发财。

### 2.3 无财库的结论

只有同时缺少财库、强偏财、爆发型财富通路和岁运强引动时，才输出：

> 你的钱更适合一点点做大，不属于靠一次押中就突然翻身的类型。长期把主业、客户或项目做稳，比追逐短期机会更容易真正积累下来。

如果虽无财库，但存在强偏财、食伤生财、从财或明确岁运引动，则按实际通路输出，不使用上述保守结论。

## 3. 得财方向

方向映射采用：

- 木：东方、东南
- 火：南方
- 土：本地、中央区域或稳定扎根型市场
- 金：西方、西北
- 水：北方

方向选择顺序：

1. 从真实财富通路涉及的五行中，优先选择属于用神或喜神者。
2. 没有明确财富通路时，优先用神，其次喜神。
3. 忌神方向只作为需要谨慎的方向，不得包装成旺财方向。
4. 若证据冲突，输出“得财方向不集中”，不强行指定单一方向。

用户文案必须说明为什么：

> 你更容易从东方和东南方向打开收入。这里的“方向”不只是搬家，也包括这些方向的客户、市场、合作方和工作机会。木是你的用神，并且命局中的木能接入现有赚钱通路，所以这个方向更容易把机会变成收入。

不输出城市名单，不承诺去某个方向一定发财。

## 4. 财富页面结构

财富板块收拢为四部分：

1. **财富量级与一句话结论**：保留 A1—A10，同时用一句话明确属于稳定积累、项目放大、团队经营或机会爆发。
2. **钱主要从哪里来**：把财星、承载和赚钱路径合并成一段，不再各占一张卡片。
3. **钱能不能留下**：统一解释财库、库中藏干、比劫分财和其他留存风险。
4. **哪里更容易打开财路**：显示有利方向、原因和实际对应的客户/市场/平台/合作方式。

命理依据仍保留为小字，但白话结论是视觉主体。

## 5. 学业三档

内部数值继续保留用于稳定计算，用户只看到三档：

- **高学历**：原内部 8—10 档。文案为“本科相对轻松，具备研究生或更高层级深造潜力”，并说明优势与可能拖后腿的环节。
- **普通学历**：原内部 4—7 档。文案按具体分数分成“本科需要更多努力”“本科有机会，稳定性决定结果”“本科基础较稳，继续深造需要持续投入”，但页面等级统一显示“普通学历”。
- **低学历**：原内部 1—3 档。文案为“传统应试会明显吃力，要达到本科需要比多数人投入更多时间和稳定训练”，不得写“考不上”“只能大专”。

三档仍由杀印相生、官印相生、食神制杀、伤官合杀、金水相涵、木火通明及反向阻断共同计算，不靠安慰性文案抬高等级。

## 6. 大白话规范

禁止单独面向用户使用：

- 消耗、纠缠、失衡、结构张力、资源分流、承载不足、关系波动等抽象词。

必须翻译为具体表现。例如：

- “关系纠缠”改成“会反复怀疑对方到底靠不靠谱、这段感情还能不能继续走下去；两个人一阵亲近、一阵疏远，明明互相牵挂，却总是很难长期保持稳定”。
- “财富分流”改成“钱进来以后，容易继续投进项目、被合作伙伴分走，或者被家庭和责任性支出带走”。
- “承载不足”改成“机会一多，你需要垫的钱、扛的责任和投入的精力也一起增加，最后赚得不少，真正留下的却不一定多”。

测试将扫描所有付费板块，防止这些术语再次进入用户可见文案。

## 7. 四柱反查与大运状态

正式四柱入口保持现有逻辑：用户选中候选后，URL 携带四柱、`timing=matched`、出生年月日、时辰索引和中点钟点。

修复内容：

1. 本地验收示例采用反查结果 `1990-07-12 18:00`，使庚午、癸未、戊寅、辛酉命盘显示真实大运。
2. 深度报告明确区分：
   - `unknown_birth`：出生时间未定位，无法计算大运；
   - `before_start`：出生信息完整，但尚未到起运时间，显示“起运前”；
   - `active`：显示实际大运干支与起止年份。
3. 已选择候选却丢失日期或钟点时，测试必须失败，不允许静默降级成“未定”。
