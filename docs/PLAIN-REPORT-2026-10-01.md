# 白话深度报告改造（2026-10-01，本地未推送）

用户要求报告有依据、讲具体事情、普通人能读懂；有利与不利都直说，保留财富 A 等级和关系等看点，不用术语、空话、重复的待核提示填充正文。不是增加固定句子的数量，也不是为了显得准确而把推断说成现实事实。本批从 main / 489bebc 开始，未推送、部署或写入生产数据。

## 根因与改动

- `result.js/reportText` 原来会无条件把亏损、损失改成资源波动，分手改成关系边界调整，也会破坏否定句。已移除此类展示层语义改写；新报告保留原意、HTML 转义和证据。旧结构卡片的绝对灾难断语单独明确隐藏，不改写成好话。
- `report-imagery.js` 将校准问卷和报告正文分开。31 种机制、7 种现实场景共 217 条专用表达，另有财富领域分支。新增 `getReportScenario`，返回 reportLabel / reportBaseline / meaningKey / scene；校准问题、选项 ID、manifestation 及判定规则不变，场景矩阵散列有回归保护。
- `calibration-model.js` 将 reportBaseline、reportLabel 和新语义身份一并传入报告。问卷的“是否发生、请选择、不算”等不再用作未来结论；真实反馈仍只修正报告解释，不改变命盘事实或父母关系。
- `deep-report.js` 优先保留不同具体事件，兜底按学生、备考、工作、求职、居家、退休等场景表达，修复儿童合同续约、成人备考被当作未挣钱学生、泛化健康提示等问题。家庭身体状况方向只在已有相应线索时表达；普通家务变化不自动归为家人身体问题。无医院、具体病名部位、检查或治疗建议。
- 今年和五年正文采用同一份主次事件裁决，不能再同时拼上相反的宽泛领域句；喜用数量不另推现实年度利好。相同事件跨年出现时用明确年份引用，完整解释与当年依据保留在展开层。分领域时间卡对相同事件合并年份。
- 财富 A 评分算法保留；钱的来源、持续进账、合作分配、投入、存款分开。保留忌财库占用风险、偏财机会性和无财库分次积累的区别。弱方位、缺乏来源和早年窗口说明移入补充依据。学生区分长期潜力与当前开支；备考不意味着未就业，居家和退休涉及合作收入时说明条件。
- 感情正文改为付出回应、谁做决定、改约、翻旧账、闷着不说等具体相处情境；弱年龄、外貌、认识渠道证据折叠，不编造确定人物画像。未成年章节为“相处与沟通”，没有婚嫁预测。
- 学习正文分别说明理解、答题、坚持和实际使用，不再重复“本项传统结构线索、需要核对”的包装，也不以聪明、学历保证美化。
- `result.js` 默认只展开正文；逐条依据、技术判断、条件和弱线索用 details 保存。按语义身份与作用去重，重复结论仍保留全部证据；PDF 导出继续展开这些依据。资源版本更新为 deep-report 35 / result 60 / report-imagery 7 / calibration-model 6。

## 兼容与边界

新报告依旧从当前命盘生成，不写回历史报告、档案或反馈。没有 eventAdjudication 的旧账本保留风险/缓解优先级兼容分支；它不是新报告的默认路径，也不另外用五行角色数量输出现实利好。资料缺失时不能凭空补事件。

全局只保留一次“传统命理解释不等于已发生事实”的阅读说明，各结论具体前提可展开。直白表达不能把传统取象当作已被验证的因果规律；本批没有测量现实预测准确率，也没有修改计算权重。
