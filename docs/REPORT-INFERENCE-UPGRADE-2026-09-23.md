## 报告

报告schema更新为`2.1.0`。每段新增`claimKey/sourceRefs/ruleId/status/scope/conditions/blockers/requiredConditions/realityConfirmed`，保留原`title/sourceText/outcomeText/text/basis`接口。证据状态是规则属性，不是现实命中概率；没有把多项派生线索机械计为更高可信度。

### 明确矛盾

- 财富承接状态与主旺衰分开，主盘中和不再被正文写成偏强；从格主线按顺势方法，不套普通弱命补扶。
- 配偶星“透藏并见”正确进入显现且有根的分支；不再用是否包含“透干”两个字代替完整可见性状态。
- 年龄未定保留未定；认识渠道消费综合位置判断，不能按数组第一项任意决定。外形消费底层取象结论，不额外补五官、身高与体型。
- 夫妻宫事件保留具体来源、关系类型与并存事实。天干作用须确与配偶星相关才进入婚恋段，不能把任何日干受克都写成伴侣争主导权。合会未核成化时只列关系线索，不由目标五行直接定现实感情结果。
- 成年阶段有具体候选场景时优先消费候选，避免统一年龄模板覆盖；儿童、教育与晚年仍保留阶段过滤，防止给儿童成人婚嫁或收入场景。
- 缺少财富/婚恋/学业必要字段时输出资料不足，不默认生成A6、低学历或配偶年龄。正常有效命盘的A6公开下限保留。

### 保留卖点并约束结论

A6—A10等级及原评分机制、财富通路、相处画像、学习类型与年度窗口保留。A等级表述为模型潜力参考，不当成已验证的终身净资产上限；现实财富校对仍不反向改写原局A等级。

财富段列有利通路是否存在及留存阻断；没有通路不补定工资、横财来源。方位保留传统取象，不再承诺某方向客户更会带来收入。学业保留学习和深造潜力，取消由内部等级直接肯定“本科相对轻松/本科通常可达”。没有年度强触发时保留窗口待定，不确认现实一定平稳。

本轮未新增现实反馈数据库或自动校正评分；真实准确率仍需独立样本。画像与年度正文仍属于传统规则下的条件性解读，不是对现实人生结果的因果证明。
