## 〇、样本与基建（含勘误）

- **样本**：28 盘 = 22 盘基线（`_baseline_22.csv`）+ P1.5 六盘永久回归样本（冻结锚点：用神/喜忌/忌神不变=锚点✓，终分/旺衰变化如实报告）。
- **勘误（重要）**：此前交付的 P2 审计报告（`2026-08-13-p2-audit.md`）初版数字基于错误样本——实验脚本误把 `_p15_charts.txt` 全部 20 盘 P15 载入，实际跑了 42 盘而分母硬编码 28。现两脚本均已加 SIX_IDS 过滤 + `charts.length===28` 断言，全部数字已按 28 盘正确样本重跑修正。**本报告与修正后的审计报告为准**。定性结论无一改变；差异点：V2 20→12、V7 12→10、V8 25→15、V9 25→16，V4 的「P15-19 用神翻转」在 28 盘设计样本中不存在（该盘属 20 盘盲测集）。
- **防静默失效**：bazi.js 为 CRLF 行尾，多行补丁均用 `\r?\n` 正则锚定；每个补丁带 CF 标记，装载时断言补丁确已写入，否则抛错。
- **红线**：波及 > 9/28 即触发「全局规则」暂停。

## 一、P2.1 合化三档（P21）

**规格→补丁**：在日支合化重构块内，先判「化神透干（年/月/时干）且合局无强冲破坏」——是→真化 ×1.0；否→趋化 ×0.5。合而不化（化神不得月令）维持现状（不重构、仅合绊 -1）。

**结果：波及 0/28 盘。六盘锚点全 ✓。**

### P15-15 真化判定（关键张力，须 GPT 裁决）

P15-15 癸未 戊午 乙卯 丙戌（卯戌合火）逐条判定：

| 真化条件（GPT Q1 标准） | 判定 |
|---|---|
| 化神得令（火===月令午） | ✓ |
| 化神透干（丙时干透火） | ✓ |
| 合局未被强冲破坏（全盘无酉冲卯、无辰冲戌） | ✓ |

三条件全满足 → **真化 ×1.0 → 19 分不变**。三档对 P15-15 的终分梯度（探索期 V1/V6 实测）：

| 档位 | 终分 | 旺衰 |
|---|---|---|
| 真化（P21 现状等效） | 19 | 极弱 |
| 趋化 ×0.5（V6） | 28.5 | 极弱 |
| 不化（V1） | 38 | 偏弱 |

**张力**：GPT Q5 曾预期「合化分级落地后 P15-15 的极端 -22 很可能自然消失」——本实验证伪：按 Q1 自己定义的真化标准，P15-15 就是真化盘，分级不改变它。且即便降为趋化也只是 28.5（仍极弱），**只有「不化」档能让此盘离开极弱**，而该盘三条件均有实据，无正当理由连降两档。

两条路请 GPT 定：
- **路 A（接受真化）**：P15-15 作为真化黄金盘保留，Q5 预期撤回；-22 极端值的修正寄托于⑧段封顶（但封顶已暂缓，等于暂时维持现状）。此路下 P21 放行为**零经验波及的规格固化**——价值在未来盘（趋化盘多得 0.5 权重），28 盘样本内无任何盘命中趋化档。
- **路 B（加严真化判定）**：需 GPT 给可操作定义——「透干」是否须贴身（月干/时干）？「强冲破坏」是否扩及刑/害/冲绊？按此定义 P15-15 或降至趋化 → 28.5 仍极弱 → Q5 预期仍不达成（除非加严到不化档，即否定火令本身，无依据）。

**事实陈述**：P21 补丁在 28 盘样本上 0 波及、0 翻转、六盘锚点全过，本身无红线风险；但它对设计样本没有任何可观测改进，其全部价值取决于 GPT 对上述张力的裁决。
