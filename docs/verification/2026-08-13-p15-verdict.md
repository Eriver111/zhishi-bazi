## P2 设计阶段：审计六项（优先级排序）

1. **合化判定**（第一优先）：合/合绊/合而趋化/真正合化分离，日支重构规则重审（P15-15 黄金盘）——一次可造 ±19 分
2. **根气体系**（第二）：日支自坐与年/月/时支通根的权重差（P15-16）——一次可造 ±9~12 分
3. **⑧½ +13/0 断崖**（第三）：改连续/分级结构贡献（P15-14）——一次 ±13 分
4. **①⑤重复性**：得令已表达季节强弱后，⑤额外克泄耗的合理补量（P15-12）
5. **⑧关系叠加/距离**：同一支同时冲/合/半会时处罚能否无限累计；月日冲/跨柱合/遥合倍率合理性
6. **⑤官杀成势零罚**（P15-14 延伸）：⑤只罚囚令/休令、克我者成势零罚——反事实 V7 已证明补罚波及 12/28 盘不可接受，倾向移交结构层「官杀成势」风险类型
