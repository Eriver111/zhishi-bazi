标签按第四轮裁决修正（H06 合而不化→趋化、H18 趋化→真化，均为午未合土口径下的事实裁决，无盘号特判），最小规则集重跑结果：

**18/18 全一致**（对角矩阵，无冲突盘）。真化集 8 盘：H01 H02 H03 H07 H10 H13 H14 H18；趋化集 9 盘：H04 H05 H06 H08 H09 H11 H12 H16 H17；合而不化 1 盘：H15。

其中 H18 的证据链证实了第三轮的事实更正：**月干己土透**（五虎遁断言确认「己未」合法月柱）→ S1(未=土) + T2(月己透) + 无D → 真化。H06 按 GPT 自述骨架落入 S2(土在午月相) + T2(时戊透) → 趋化。两盘均未使用任何午未特殊规则——第三轮提交的「两冲突盘恰为全部午未合盘」模式，经标签修正后自然消解。

### qualification v1 规格（FROZEN，本轮以后不再调资格规则）

1. **S 档**：S1 月支五行 === 化神五行（强支持）/ S2 化神在月令为旺·相（次级支持）/ S0 休囚死（无支持）
2. **T 档**：T2 月干或时干透化神（近透）/ T1 仅年干透（远透）/ T0 无透
3. **D 档**：R1 合局成员遭第三支直接六冲、R2 月令受冲 → 仅将「真化候选」降一级
4. **刑、害**：只记录（进入 relationEvents），不参与合化资格
5. **多合事件**：仅增强 qualificationStrength 证据；同一日支状态转换只执行一次（事件可多条，实体转换一次）
6. **判定**：S1+T2+无D → 真化；其余 S1 → 趋化；S2 → 趋化；S0 → 合而不化
7. （S2 下 T 档不产生资格差异——先接受，字段仅作证据保存，待更大样本再议）

冻结验证脚本带硬断言：若一致率 ≠ 18/18 立即抛错停止，未修改规则追标签。

## 二、完整模型定义（M-A / M-B / M-C）

每个模型 = qualification v1 + 经典午未合土口径 + 分层烈度（整体替换引擎「日支被合化」块的内存补丁，CF-P2.1G 标记断言）：

| 层级 | M-A | M-B | M-C |
|---|---|---|---|
| 真化 O/N | 0.5 / 0.75 | 0.5 / 0.75 | 0.5 / 0.75 |
| 趋化 O/N | **0.75 / 0.50** | **0.75 / 0.375** | **0.875 / 0.50** |
| 不化 O/N | 1 / 0（不变换） | 1 / 0 | 1 / 0 |

真化系数即 GPT 暂定候选（originalResidual=0.5 → 旧侧退还×0.5；newEffect=0.75）。O = 旧侧退还比例，N = 新侧作用比例。

## 五、三模型差异小结与 Claude 建议

三模型在硬性指标上完全同分：资格 18/18、基线影响集 {A5, P15-15}、六盘锚点全过、用神零翻转。差异集中在：

1. **五档翻转**：M-A 5 处 vs M-B/M-C 6 处（差 H04 跨线）。
2. **方向保真**：M-A 0 反转（H08 恰好归零、H18 由真化系数所致且三模型相同）；M-B/M-C 各 3 处趋化反转（H04/H05/H08）。
3. **系数简洁性**：M-A（0.75/0.5，公分母 2，解释直观「旧侧保留四分之三、新侧生效一半」）优于 M-C（0.875）与 M-B（0.375）。

**Claude 建议选 M-A**，两条独立理由：(1) 按 GPT 裁决口径「差异都很小则选系数最简、解释最直观」——M-A 最简；(2) 方向保真最好——M-B/M-C 使 H04/H05/H08 三盘的合化效果反向（旧引擎负向变正向、正向变负向），M-A 无一反转。H18 的方向反转与候选无关，若 GPT 后续想消除，只能动真化系数（如 0.5/0.5 或 0.75/0.75 对称档），不在本轮范围。
