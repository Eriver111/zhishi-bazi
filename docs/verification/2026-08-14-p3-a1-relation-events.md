## 3. structuralRisks 原型（裁决第 6 条）

七类检测器（每类输出：`type / severity(存在|潜在) / parties / why / mitigations / triggerHint / evidence`）：

| 检测器 | 原型规则 | 全样本命中 |
|---|---|---|
| 伤官见官 | 天干同透伤官+正官；制化检查=五合绊/财星通关/位距 | 6 |
| 财破印 | 天干财元素克印元素 | 16 |
| 枭夺食 | 天干偏印元素克食神元素 | 6 |
| 官杀混杂 | 正官与七杀同透（**透干口径**，藏干不透不判） | 1 |
| 杀重无制 | 杀透≥2 且无食伤/印透=存在；单杀无制=潜在 | 3 |
| 关键用神/格局节点受冲 | 六冲命中节点：用神同五行/用神干之禄/日主之禄/印星之根/七杀之根 | 20 |
| 财印冲 / 官印冲 | 六冲对主气一财一印 / 一官杀一印 | 8 |

原则落地：**「存在关系」≠「一定是风险」**——每个风险必须回答：是否直接作用关键目标 / 位置距离 / 强弱 / 是否有合制化 / 是否只是潜在触发。severity 分级：贴身且无制化 → `存在`；远隔或有合绊 → `潜在`。
triggerHints 一律条件语言（"进一步增强时可能…"），脚本硬断言：全部 hint 不含"必凶"、必须含"可能"或"若"条件词。
