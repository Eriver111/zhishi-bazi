# 知时判读规则记录 v1

版本：`zhishi-judgement-v1-20260922`。用途：记录本轮可以验收的事实约束和采用口径，供审计 `ruleVersion` 与来源引用。它不是全部命理规则的权威定本；权重和流派问题仍需有来源的独立判读复核。本轮沿用既有项目取法，修正其内部矛盾，没有新增所谓古籍定论。

## 规则与否决条件

| 编号 | 采用规则 | 否决、边界与验证 |
| --- | --- | --- |
| J-STEM-01 | 天干是否合化统一读取 `getGanHe`。旺衰、说明使用同一裁决；只有相邻且已化的关系进入合化分。 | 得化神月令不能覆盖争合、局外阻化或隔柱不化。保留现有已化加减幅度（同类+2、印+1、其他-1），不以这些系数声称传统命理精确量化。五种化神均有阻化反例及无阻正例。 |
| J-STEM-02 | 月日、日时合而不化时，沿用既有克泄耗返还；争合则减半。 | 是否争合也读取同一关系裁决，年干参与争合不能被漏掉。已化与合绊返还互斥；生扶不走该返还。原系数0.4/0.2保持。 |
| J-POSITION-01 | 地支关系是否涉及日柱，只认实际柱位。根气受损使用独立根气证据。 | 年、月地支与日支重字，不等于年、月关系发生在日柱；不能据此增加涉日扣分。真实月日、日时关系的原强度保持。 |
| J-WUWEI-01 | 午未只由 `resolveWuWeiInteraction` 选择完整三会火、火势、趋土或合绊。 | 火势交由原半会/三会结算；趋土只作既有轻度修正；合绊不转五行。通用日支六合转换必须排除午未，不能再固定将午火化土。其他六合仍保留原路径。 |
| J-FOLLOWING-01 | 正式从格、专旺须经过既有成立门槛；候选与成立分开。 | 候选不得触发正式从格的格局覆盖和喜忌反转。本轮不调整真从/假从及专旺门槛，也不凭审计标签迁就结论。 |
| J-RESULT-01 | 专业输出以 `getYongJi().resolvedPattern` 为最终格局，基础格局另存。 | 取格名称、成破状态、兼见结构不可混为一项；基础格不能冒充最终裁决。旺衰、喜用忌、报告读取同一事实；条件喜用不等于无限增补建议。 |
| J-AUDIT-01 | 判读先冻结再捕获引擎，新批次须有完整结构化判读、规则版本、来源与复核记录。 | 只有标题的文档、已看引擎的判读、未决争议或被隔离的错误裁判不能作为验收答案。内部/AI复核不能自称外部权威。 |
| J-COMPARE-01 | 强弱方向、具体档位、从格名称/状态、首用五行、喜忌集合、格局名称/状态逐项精确比较。 | 偏弱与极弱最多表示方向一致，不能算档位一致；喜神集合只部分重合不能算完全一致。待定项单独列出，不计作通过。 |

## 当前明确保留的待审范围

旺衰30/40/60/80档位边界、从格真从与假从门槛、候选15分边界，以及扶抑、格局救应、调候的完整优先级，本轮均未重新标定。它们不能因为本轮程序回归通过就被宣称为已经验证正确。

下一批判读复核应优先覆盖失令有强根、得令但生扶受阻、印旺但埋金/漂木、强弱临界、微根破从和调候与扶抑方向冲突。每个结论需记录实际作用的柱位和载体、必要条件、反证及采用口径；无法定论时保留待定或争议，不能杜撰唯一答案。

## 本轮验证材料的性质

- `tests/bazi-judgement-settlement.test.js` 的构造四柱用于机制回归，512个日期用于跨模块一致性检查；不是外部盲审答案。
- 固定种子10,000日期（9,837组不同四柱）用于前后影响统计；独立裁判未参与，不能据此计算命理准确率。
- 历史53盘继续逐字段回归；四份旧CSV不改，仅在测试中逐项登记能够归因的分差。
- 历史8轮80盘保留冻结原件。`audits/bazi/judgement-quality.json` 记录两盘事实错误及待复核状态；它没有提供新的旺衰或取用答案。
