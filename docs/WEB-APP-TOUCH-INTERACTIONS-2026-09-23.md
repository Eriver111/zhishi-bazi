# 手机端触控交互升级（2026-09-23）

本轮依据用户希望网站更像 Web App 的要求，检查现有底部导航、日期滚轮、表单及阅读状态恢复，优先补齐出生地点选择和档案操作。已有导航和个人排盘日期滚轮继续复用。

## 交互变化

| 场景 | 手机端（宽度不超过 700px） | 桌面端 |
| --- | --- | --- |
| 个人、合盘、紫微出生地点 | 可搜索的底部面板，省市区逐级选择，确认后写回 | 保留原选择控件及编辑入口 |
| 档案打开 | 整卡点击，更多按钮唤起底部操作面板 | 保留直接操作按钮 |
| 档案快捷操作 | 长按可打开同一面板；移动手指取消长按 | 原点击操作 |
| 长档案列表 | 首批 20 条，接近底部追加，保留加载更多按钮 | 显示完整列表 |
| 返回档案 | 恢复搜索、筛选、已显示数量及滚动位置 | 同样恢复界面状态 |

地点面板展示完整地区路径，支持同名地区区分。草稿与原字段分离，取消不改值；确认时按省、市、区的依赖顺序触发原字段事件。合盘双方分别绑定各自表单。没有自动获取当前位置。复用原有地点入口，避免重复按钮和嵌套弹层。

共享底部面板采用原生 dialog，处理焦点返回、背景滚动、键盘视口、安全区、Esc 及浏览器返回键。关闭后再执行跳转操作，避免遗留面板历史记录。按钮提供可见入口，长按只是快捷方式。

档案按账号隔离界面状态；退出或切换身份后清空界面，忽略旧账号迟到的请求。删除仍需原确认步骤，保存失败不呈现为成功。搜索支持档案显示名称，加载失败可以重试。

## 范围及限制

- 档案仍通过既有接口读取完整列表；本轮优化是 DOM 分批渲染，不是服务端分页。
- 没有将下拉刷新加到表单或报告，避免打断填写、阅读。没有为当前不存在的图片相册或批量业务增加手势。
- 没有修改算法、家庭关系、报告规则、支付接口、数据库结构或生产配置。
- 原生 iPhone Safari、微信内置浏览器尚未真机验证；本轮是 Chromium/Edge 浏览器宽度与触控模拟。
