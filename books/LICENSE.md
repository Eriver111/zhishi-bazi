阅读页默认显示自动繁转简的版本，原文同时保存，可用“原文”按钮对照。简体版沿用相同的录文许可、章节标识与段落顺序，不属于白话翻译。紫微三处无标点长段另提供保留原字的阅读标点，并在章节提示；“原文”仍显示未改动的录文。字形转换在构建时使用 [opencc-js 1.4.2](https://github.com/nk2028/opencc-js)（代码 MIT、所用 OpenCC 数据 Apache-2.0）；转换器不随阅读页加载。原字形字段为 title/text，简体字段为 titleSimplified/textSimplified。

每个 JSON 中的 `sources` 保存来源标题、原文链接和所取 HTML 或网页文本快照的 SHA-256；维基文库来源另有修订编号、固定链接，`retrievedAt` 保存取录日期。固定链接可追溯编辑历史；维基页面可能引用其他页面，固定主页面修订号不能保证其引用内容永久不变，仓库内 JSON 是本次整理后实际发布的快照。

古籍内容反映其历史时期的观念与术数论述，仅供文化阅读研究，不是现代医学或现实预测效果的证据。
