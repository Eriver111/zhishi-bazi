## 二、新发现（本次盲盘唯一贡献点）：2 个明确机制缺陷

### A1（明确缺陷·影响格局名+状态）M15：甲木卯月透乙 → 误判「建禄格」

- **引擎输出**：建禄格·成格（type=透干取格），文案"月令为日主禄位（同五行）"
- **事实**：卯 = 甲木**帝旺（羊刃）位**，非禄位（甲禄在寅）。M02 庚酉→羊刃格 ✓、M17 丙午→羊刃格 ✓，唯独甲卯错判。
- **根因**（bazi.js:4269-4349）：v5.6 注释写明"月支为日主临官/帝旺，直接定建禄/羊刃格；同五行透干不可覆盖十二长生判定"。但 4335-4338 的特判带 `!matchedSS` 守卫——M15 月支卯藏乙透月干 → matchedSS=劫财 → **特判被跳过** → PATTERNS['劫财'] 不存在 → 4343 fallback"同五行→建禄格"。守卫漏洞正是注释所警告的"丁巳月被错误判定为建禄格"同款路径（丁巳月丙透即触发）。
- **影响**：不止格局名——成格/破格条件从"官杀制刃"换成"财官透出为用"：M15 无官杀透（仅丑藏辛）而有戊财透 → 建禄·成格；若按羊刃格判 → **羊刃无制·破格，状态翻转**。
- **影响面**：五阳干刃月藏干透干的所有盘：甲卯透乙 / 丙午透丁 / 戊午透己 / 庚酉透辛 / 壬子透癸。
- **用神/旺衰不受影响**（4694 行建禄/羊刃共用同一 L3 口径，本批 M15 用金喜金火土自洽）。

### A2（明确缺陷·仅表达层）M14：同柱复合格局提前 return，绕过「从格优先于正格」

- **现象**：M14 格局显示"伤官生财格·成格"（未替换），从格块另显示"假从势格"；M01/M03 格局名则正确替换为"从杀格/假从势格"。同机制三盘三种表现。
- **根因**（bazi.js:4321-4330 vs 4361-4369）：同柱复合检测命中后 `return` 提前退出，而"从格优先于正格"（4361 注释原文"从格成则舍正格而从之"）的替换逻辑在其后——compound 盘永远到不了替换。M01/M03 非 compound 所以替换成功。
- **影响**：页面同时出现两个格局名（伤官生财格·成格 + 假从势格），表达混乱；用神不受影响（getYongJi 独立查从格，method=从格顺势 ✓）。
- **影响面**：任何「同柱复合 + 从格」组合盘（食神生财/伤官生财/财生官等 + 从势/从财/从儿）。

## 六、建议

- **A1/A2 是否打开冻结由 GPT 裁**。我方独立判断：两者都是引擎自己文档意图（v5.6 注释 / "从格优先"注释）的违反，修复外科式（A1=特判守卫条件；A2=从格替换提前到 compound return 之前），且 A1 影响成格/破格状态（非仅格局名，GPT 的"格局名差异不影响旺衰用神"启发式在此不适用）。修复后需重跑 50 盘回归 + 本 20 盲盘确认无涟漪。
- **C1/C2** 不动引擎，属文案层（调候库文案 / 旺衰话术），可后续随 prompt 迭代处理，不阻塞。
