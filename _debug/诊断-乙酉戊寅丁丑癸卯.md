# 诊断：乙酉 戊寅 丁丑 癸卯 ——「寅里藏乙」文案 + 正印格判定（2026-08-15）

> 用户报告：寅里藏甲丙戊，网站为什么判定「寅里藏乙」并判正印格。
> 结论先行：**格局判定（正印格）正确；「寅里藏乙」是 source 文案 bug——乙是透干不是藏干，且乙=偏印与「→ 正印」自相矛盾。**

## 一、复现事实（引擎实测）

- 寅藏干 = `["甲","丙","戊"]`（无乙）
- 丁对甲（本气）十神 = **正印**；丁对乙 = 偏印
- getPattern：`正印格·成格`，type=`透干取格`，source=**「月支寅藏乙，透于年柱(同木透) → 正印」**
- 旺衰：偏强 63 分；用神=金，喜=金土木？(实测 金/土/水)，忌=木火；method=扶抑为主

## 二、为什么判「正印格」——判定正确

丁生寅月：寅本气甲木，甲为丁之正印 → **月令本气为正印 → 正印格**（《子平真诠》月令取格口径）。

年干透乙（偏印，与甲同五行木）：getPattern 4235-4237 注释「四生四正月仍只认本气（或本气同五行的透干）」→ 透乙仍取本气甲定格 → 正印格 ✓。

（严格子平有「寅月透乙论偏印当令」的讨论，但「月令本气定格」是网站既定的主流口径之一，判定不算错。）

## 三、Root Cause——「寅里藏乙」怎么来的

同五行兜底分支（bazi.js 4276-4285）与 source 模板（4378-4382）的语义错配：

```js
// 4276-4285：月支藏干无精确透干匹配时，找与本气同五行的天干兜底
if (!matchedSS && !isLinGuanOrDiWang) {
  for (var gi = 0; gi < allGan.length; gi++) {
    if (WU_XING[allGan[gi]] === benQiWx && allGan[gi] !== benQi) {
      matchedSS = getShiShen(dayGan, benQi);   // 十神用本气甲 → 正印 ✓
      matchedGan = allGan[gi];                  // ← 存的是【透干】乙！
      matchedPillar = pillarNames[gi] + '柱(同' + benQiWx + '透)';
      break;
    }
  }
}
// 4378-4382：source 模板假设 matchedGan 是【藏干】
var source = specialGrid
  ? '月支' + mZhi + '（' + ss + '）'
  : matchedSS
    ? '月支' + mZhi + '藏' + matchedGan + '，透于' + matchedPillar + ' → ' + ss
    : '月支' + mZhi + '（' + ss + '）';
```

- **精确匹配分支**（4251-4260）：matchedGan = 藏干 = 透干（同一字）→「藏{matchedGan}」正确。
- **同五行兜底分支**：matchedGan = 透干 ≠ 藏干 →「藏{matchedGan}」把透干写成了藏干 →「寅藏乙」。
- 十神名 ss 却用本气甲（正印）→ 与「藏乙（偏印）」并列 → 自相矛盾。

## 四、影响面（对照验证实测）

|---|---|---|---|
| 丁@寅透乙（用户盘） | 甲丙戊 | ❌「寅藏乙」→ 正印 | 正印格·成格（对） |

## 五、喜用忌点评

- 旺衰 63 偏强：寅卯印 + 乙木透 + 丑土（丁墓）——印比两旺，偏强合理 ✓
- 用金（财）、喜金土水、忌木火：身强忌印比，用财官食伤 ✓
- 印格身强而用财（金），正合「印格身强，财星损印为用」传统口径 ✓
- method=扶抑为主 ✓（无调候/救应场景）
- 成格条件「日主有承载格局之力（63 分偏强）」+「无财星破印（天干无金透）」+「有根纳印」——口径自洽，但「有根纳印」的根判定细节（丁墓于丑如何算根）可另行复核。

## 六、修复建议（待裁决，本诊断未改任何代码）

最小修复：source 模板区分「matchedGan 是否等于本气」：

```js
var source = specialGrid
  ? '月支' + mZhi + '（' + ss + '）'
  : matchedSS
    ? (matchedGan === benQi
        ? '月支' + mZhi + '藏' + matchedGan + '，透于' + matchedPillar + ' → ' + ss
        : '月支' + mZhi + '本气' + benQi + '（' + ss + '），' + matchedPillar + '透' + matchedGan + ' → ' + ss)
    : '月支' + mZhi + '（' + ss + '）';
```

产出示例：「月支寅本气甲（正印），年柱(同木透)透乙 → 正印」——语义完整、不再矛盾。

**冻结面提示**：getPattern 属 `CORE_ENGINE_FROZEN_AFTER_P4A`。本修复只改 source 文案（不进评分核心、不改 name/status/type），按冻结纪律属「解释文案修复」，建议并入给 GPT 的审阅材料一并裁决后再动。
